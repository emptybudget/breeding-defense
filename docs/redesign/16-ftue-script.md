## 구현 사양 — `FtueController` (scenes 신규, 렌더 전용)

```ts
// src/scenes/FtueController.ts — 데이터 레이어 오염 금지 (GameState 읽기 전용)
export type FtueStepId = 'F1' | 'F2' | ... | 'F13';
// MetaProgress에 ftueDone: FtueStepId[] 추가 (스키마 v2에 포함)
```

- **스포트라이트**: 전체 딤(0.6) Graphics + 대상 영역 구멍(`beginPath` 사각/원 컷) + 금테 펄스. 대상 좌표는 렌더러가 제공하는 게터 사용 (하드코딩 금지).
- **고스트**: Graphics 원(반지름 14, CREAM 0.8) — 탭형은 scale 1→0.7 반복, 드래그형은 시작→끝 좌표 tween 반복(1.2s 루프).
- **강제 스텝**(F1·F5·F6·F8): 스포트라이트 밖 입력 차단(딤 레이어 `setInteractive`로 흡수, 대상만 통과). 완료 판정은 기존 이벤트 훅 재사용 (소환 콜백·둥지 투입·교배 확정·합성 발생).
- **비강제 스텝**: 입력 차단 없음, N초 후 자동 해제 + 아무 탭으로 즉시 해제.
- **1배속 강제** (v3 R3): 스텝 활성 중 `speedMult` 1로 강제, 해제 시 복원 — 순수 TS 테스트 대상 (M4 완료 판정 기존 항목).
- **동시 발생 큐**: 스텝은 동시 1개만 — 트리거 충족 시 활성 스텝 있으면 대기열(FIFO). 13-E14 배너 우선순위와 독립 (FTUE는 딤 레이어라 충돌 없음).
- **1회성**: 완료 즉시 `ftueDone` 기록+저장. 트리거 검사는 `!ftueDone.includes(id)` 선행.

## 스킵·리셋 정책

- **건너뛰기**: 강제 스텝 포함 모든 스텝에 우상단 "건너뛰기" 항시 표시 — 탭 시 해당 스테이지의 잔여 스텝 전부 done 처리 (강제 스텝에서 막히는 유저 방지).
- **기존 유저**: 리디자인 후 UX가 전면 교체되므로 `stageRecords` 보유 유저도 **FTUE 재노출** (마이그레이션에서 ftueDone 초기화). 단 W1 재클리어는 요구하지 않음 — 해금 상태 유지.
- **리셋**: 일시정지 팝업에 "튜토리얼 다시 보기" (ftueDone 초기화) — P3, 여유 있을 때.
