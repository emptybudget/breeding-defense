# 메인 스토리라인 — 「접경 연대기」 4막 구조

> 2026-07-06. 24번 세계관의 서사를 게임 진행(W1~W3 → 명가 패치 → v1.1+ 확장)에 매핑한 큰 축. 원칙: **텍스트 온리·전부 스킵 가능·7분 세션 불침범** (스토리는 판 사이와 클리어 순간에만 산다). 기존에 깔린 조각들(몰락 명가·유물 알·망령·왕관·Ruin의 첫 마디)을 하나의 실로 꿴다.

## 로그라인

**"잊힌 가문들의 땅에서, 이름 없는 새 가문이 신을 낳는다 — 그리고 그 신이 묻는다. 누가 우리를 잊었는지."**

## 중심 반전 (전 서사의 등뼈)

심연의 군세는 침략자가 아니다. **수백 년 전, 몰락한 명가들이 신을 낳으려다 실패했다** — 완성되지 못한 신은 산산이 부서져 균열이 되었고, 그 가문의 수호자들은 이름을 잃은 채 균열에 삼켜졌다. ELITE 망령의 "지워진 문장", TANK가 지고 오는 "가문의 성문", 왕관균열주의 "주인 모를 왕관"은 전부 이것의 복선이다. **적을 죽이는 것은 사실, 잊힌 수호자들을 쉬게 하는 일이다.**

## 4막 구조

### 1막 「문패」 — W1 (튜토리얼 5스테이지)

- 접경 끝자락의 폐가에 플레이어가 문패를 건다. 균열은 아직 잔물결 — 아무도 이 땅을 눈여겨보지 않는다. 왜 하필 이 폐가인지는 3막에서 밝혀진다 (**이곳은 몰락한 명가의 옛 터**다).
- 비트: W1-1 첫 소환("소환진이 아직 당신을 낯설어한다") → W1-2 첫 교배(첫 혈통 탄생 = 가문의 진짜 시작) → W1-5 첫 보스 격파 후 **T4 컷인 = 선대 가주가 남긴 벽화의 환영** — "언젠가 너의 계보도 별을 품으리라." (컷인에 서사 부여)
- 막 종료 카피: *"접경이 새 문패의 이름을 물었다."*

### 2막 「수복」 — W2~W3 (본게임 10스테이지)

- 가문이 이름을 얻고 접경 안쪽으로. 균열주(BOSS)들과의 소모전.
- 비트(스테이지 클리어 1줄 연대기로 분산): W2-3 "망령의 로브 아래에서 낡은 문장 조각이 떨어졌다 — 어느 문(門)의 것도 아니었다" → W2-5 "성문을 진 거북이 지나간 자리에 무너진 저택의 주춧돌이 드러났다" → W3-3 "이 땅의 옛 지도를 찾았다. 당신의 폐가 자리에 큰 저택이 그려져 있다" → **W3-5 왕관균열주 격파: "왕관 안쪽에 새겨진 이름은, 지금은 아무도 쓰지 않는 성(姓)이었다."** — 반전의 반쪽 공개.
- 이 막에서 플레이어가 알게 되는 것: 심연은 어딘가에서 "왔다"기보다 여기서 "생겼다".

### 3막 「탄생」 — 명가 패치 엔드게임 (Gen3 T4 달성 서사)

- 플레이어 가문의 계보가 무르익어 **별의 신(Astral_God)** 을 낳는다. 신의 첫 마디는 가문의 이름 — 그러나 그 직후 짧은 두 번째 문장이 있다: *"…이 땅, 낯익다."* (Ruin 떡밥)
- 반전 전체 공개(도감 인트로 최종 장 해금): 몰락한 명가들의 실패 — **그들에게 없던 것은 힘이 아니라 '기록'이었다.** 계보를 잃고 이름이 흩어졌을 때 신이 미완으로 태어났다. 당신의 혈통서(가문 시스템)가 곧 이 세계의 안전장치라는 것 — **메타 시스템(계보 기록)에 서사적 의미 부여.**
- 별의 신은 균열을 "닫는" 게 아니라 "달랜다" — 그래서 매판 밤은 다시 온다 (**무한 반복 플레이의 서사적 정당화**: 완결이 아니라 순환).

### 4막 「잊힌 이들의 신」 — v1.1+ (L3 신들의 대립 + BM 부화당 + L5 월드 4)

- **부화당(BM1)**: 유물 알을 부화시키는 행위 = 몰락 가문의 유산 계승. 스킨·칭호가 "구매물"이 아니라 "복원된 기억"이라는 서사 (수익 콘텐츠에 이야기 옷).
- **Ruin_God 강림(L3)**: 남은 세 혈통(기갑·광란·화포)이 분노로 포개질 때, 재를 품은 알에서 두 번째 신이 태어난다. 첫 마디: *"누가 우리를 잊었지?"* — 그리고 가주(당신)의 혈통서를 보고 두 번째 문장: *"…아니. 여기, 전부 적혀 있군."* — **분노의 신이 기억의 신으로 전향하는 순간.** 진영전(신들의 대립)은 선악이 아니라 접경을 지키는 두 방식: **질서(별)와 기억(재)**.
- **월드 4 「몰락한 영지」(L5)**: 옛 저택 터로 진입 — 1막의 폐가 복선 회수, 최종 보스는 "미완의 신의 심장". 격파 서사: 파괴가 아니라 **완성** — 수백 년 만에 그 신을 마저 낳아주는 것.

## 연대기 15문장 확정본 (M2 `CHRONICLE` 데이터 — 이대로 구현)

> 규칙: 각 ≤28자, Victory 결과 카드 하단 1줄. 반전 조각은 스테이지 순서대로만 공개(순서 대조 테스트 대상). 패배 시엔 미표시(연대기는 승자의 기록).

| 스테이지 | 문구 |
|---|---|
| W1-1 | 낡은 문패가 첫 밤을 버텼다. |
| W1-2 | 첫 울음소리가 폐가를 깨웠다. |
| W1-3 | 두 아이가 하나의 이름이 되었다. |
| W1-4 | 균열이 처음으로 이쪽을 보았다. |
| W1-5 | 벽화 속 별이 오래 당신을 보고 있었다. |
| W2-1 | 접경 안쪽 길은 아무도 쓸지 않았다. |
| W2-2 | 밤의 종소리가 조금 낯설게 울렸다. |
| W2-3 | 망령의 로브에서 낡은 문장 조각이 떨어졌다. |
| W2-4 | 그 문장은 세 문(門)의 것이 아니었다. |
| W2-5 | 성문을 진 거북 뒤로 주춧돌이 드러났다. |
| W3-1 | 여기부터는 지워진 이름들의 땅이다. |

| W3-3 | 옛 지도의 큰 저택, 당신의 폐가 자리였다. |
| W3-4 | 그들은 침입하지 않았다. 돌아오고 있었다. |
| W3-5 | 왕관 안쪽의 성(姓)은, 이제 아무도 쓰지 않는다. |

**W1-5 컷인 문구** (선대 벽화의 환영): *"언젠가 너의 계보도 별을 품으리라."*

- 공개 곡선: W1 = 가문의 서정 → W2 = 위화감(문장 조각) → W3 = 반쪽 진실(지키던 자들, 저택, 성씨). 전체 진실은 3막(도감 최종 장)에서만.
- 무한 모드·재클리어 시에도 동일 문구 고정 (연대기는 "그 땅의 기록"이지 판의 기록이 아님 — 판의 기록은 계보 카드가 담당).
