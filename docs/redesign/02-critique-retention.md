# F2P 리텐션/이코노미 비평 — breeding-defense

근거: `01-understand-ux.md`, `01-understand-systems.md`, `01-understand-meta.md`, `01-understand-history.md` 인벤토리. 2026-07-06.

## 1. 첫 세션이 '내일 또 켜야지'를 만드는가 — 아니오

- **첫 판 최대 쾌감 시점이 너무 늦다.** 코어 판타지 "Pop"의 실체는 T4 Astral_God(400 DPS, T3 평균의 25배)인데, 플레이테스트 실측 T4 완성은 4~5분차이고 그것도 W2-5 풀플레이 기준. W1 튜토리얼(2~4분)에서는 합성 자체가 단계 해금이라 첫 세션 유저는 T2까지가 현실적 상한이다. 즉 **게임의 핵심 쾌감을 첫날 못 본다.**
- W1 5판의 진입 연출은 "일시정지 → 검정 0.88 덮개 + 14px 텍스트 19줄 튜토리얼 → 인트로 → 힌트 토스트"(UX §1). 매 스테이지 텍스트 벽으로 시작하는 구조는 첫 세션 몰입을 판마다 끊는다.
- 결정적으로 **2배속이 3보석짜리 메타 구매 항목**이라 D1~D3 이탈 최다 구간의 유저가 가장 느린 버전을 플레이한다(meta §4의 역설).
- 첫 세션 종료 시 "내일의 예고"가 없다. Victory 팝업은 다시하기/무한/선택 3버튼 + DPS 미터뿐 — 다음 스테이지 미리보기, 미해금 유닛 실루엣, 미완료 목표 제시 전무(meta §1).

## 2. 콘텐츠 소진 — 집중 시 2~4일, 이후 무한모드 기록뿐

- 15스테이지 첫 클리어 순 플레이 ~84분, 재도전 포함 2~4시간. 메타 업그레이드 6종 총 14보석 = 승리 약 14회로 MAX. 도감 25종이 최장축이나 보상 총 6보석(meta §2).
- 소진 후 남는 것: 무한모드 최고기록(9px 텍스트 한 줄, 랭킹·보상 연결 없음)과 잉여 보석. **더 심각하게는 W2/W3 해금 로직이 미구현**(`isWorldUnlocked()` W1만 반환)이라 현 프로덕션 빌드의 실제 콘텐츠는 튜토리얼 14분이다.

## 3. 수집욕 — 도감은 체크리스트지 애착 장치가 아니다

- 도감은 "첫 제작 기록 + 마일스톤 6보석"이 전부. 유닛은 **이름 없음, 개체 구분 없음, 판 간 성장 없음**(레벨업 항목 O는 장기 보류) — 판이 끝나면 소멸하는 소모품이라 애착이 형성될 표면이 없다.
- 시각적으로도 T3 6종·T4는 스프라이트 미확보로 **이모지 렌더**(UX §7) — 가장 희귀한 수집 대상이 가장 초라하게 보인다. "T4 만개하는 무하 액센트"라는 아트 서사(history §1)와 정반대.
- 교배라는 테마가 혈통/세대/변이 기록 같은 수집 서사를 자연스럽게 지원하는데, 15% 돌연변이조차 로그 한 줄 남지 않는다. 테마 대비 수집 시스템이 가장 저활용된 영역.

## 4. 접속 훅 — '오늘 켤 이유'가 0개

- 일일 도전(GD4)·도전과제(GD5)·일일 보상·시즌 전부 미구현(P3). 로그인 보상, 시간 경과 자원, 푸시 대상 이벤트 없음. **D1/D7 리텐션이 도감 하나에 걸려 있다**(meta §5)는 진단 그대로다.
- 랜덤 디펜스 장르 벤치마크(히어로즈 랜덤 디펜스)의 핵심 훅인 일일 시드/주간 변조가 부재하고, 트랙 5종 랜덤이 유일한 판별 변수. GD4가 P3 "출시 직후"로 밀려 있는데, 리텐션 관점에서는 **출시 전 필수**로 승격해야 한다.

## 5. 진행 체감 — "어제보다 강해졌다"가 3일 만에 멈춘다

- 장치는 메타 6종뿐이고 14보석에 끝. 이후 승리 보상 💎1은 소비처 없는 화폐(이어하기/선택지확장 소모품뿐). 영혼(💀)은 판내 화폐라 이월 없음 — **장기 파워 커브가 존재하지 않는다.**
- 강해짐의 표현도 없다: 강화 구매 시 scene.restart로 리빌드될 뿐(UX §1) "시작골드 100→160" 같은 비포/애프터 연출 부재. 판 시작 시 메타 효과 요약도 없어 구매 효능감이 증발한다.
- 실력 성장 가시화(스테이지별 별점, 클리어 시간 등급, 빌드 결과 카드 GD6)도 전부 미구현.

## 6. 현 구조에 자연스러운 수익화 3개

1. **보상형 광고 확장** — 광고부활은 UI/흐름 완성(1.5초 시뮬), SDK만 남음. 여기에 승리 보석 2배·미니보스 카드 리롤·시작 무료소환 3회 슬롯 추가. 기존 시스템에 무변경으로 부착 가능, 소프트런칭 1순위.
2. **영혼(💀) 영구화 + 2차 트리 IAP** — 판내 화폐인 영혼을 이월시켜 영구 트리(미결정 항목 "메타 2차 트리"와 합치)를 달면 보석→영혼 환전이 자연 싱크가 되고, 죽은 상품인 보석 IAP가 살아난다. 소환 자체는 판내 랜덤 유지라 기각된 "종족 선택 소환"과 충돌 없음.
3. **도감 연동 스킨/변이 컬렉션** — NovelAI 파이프라인이 이미 확립(18종 완료)되어 있어 색변형·계절 스킨의 한계비용이 낮다. 도감 마일스톤과 결합해 수집욕(§3)과 수익화를 동시에 보강. 전투력 비판매라 밸런스 무풍.

전제: 세 가지 모두 **W2/W3 해금 구현과 보석 싱크 확장이 선행**되어야 성립한다(meta §5).

## 결론

첫 세션에 Pop이 없고, 3일이면 진행이 바닥나고, 유닛에 애착이 안 생기고, 내일 켤 이유가 없다. 리텐션 위기의 뿌리는 UI가 아니라 **첫날 쾌감 전달 실패 + 영구 진행 총량 14보석**이다. 우선순위: 첫 세션 내 T4 체험 보장 → GD4 일일 도전 출시 전 승격 → 영혼 영구화 → 도감의 서사화(혈통/변이 기록).
