# 32 — T4 영혼 촉매 (T3 메인 운용화)

> 확정: 2026-07-13 (사용자 결정 A안). 원천 문제: **T4가 T3를 obsolete시켜 T3 티어가 스텝일 뿐**. M5에서 T3 스프라이트 6종 반입했는데 거의 안 보임.

## 1. 문제 (수치 근거)

| 유닛 | 유효 DPS | 스탯 |
|---|---|---|
| T4 Astral_God | 단일 33 / 군집 **~266** | 공10·0.3초·**8타겟** |
| 최강 T3 Dino_Mecha | ~20 | 공30·1.5초·1타겟 |
| 최강 T3 Cyborg_Wizard | ~18 | 공6·1초·3타겟 |

T4 ≈ T3의 **10~13배**(군집은 그 이상). 한 기만 나와도 T3 군단 무의미. + T4 합성(T3×3)이 자원 외 게이트가 없어 만들 수 있으면 무조건 만듦.

## 2. 결정 — A안: 영혼 = 합성 촉매

**T4 합성(T3+T3+세 번째 T3)에 영혼(`enhancePoints`) `TIER4_SYNTHESIS_SOUL_COST=3` 추가 요구.** 부족하면 합성 실패(알림), 성공 시 영혼 차감.

- **T4는 여전히 당신 혈통에서 태어남**(`inheritOnSynthesis` 계보/gen 승계 그대로) → 코어 판타지("교배로 기른 혈통이 神을 낳는다") 불변. 영혼은 *혈통 산물을 神으로 승격시키는 촉매*지, 혈통 없는 T4를 상점에서 사는 게 아님. → **순수 "영혼으로 T4 구매"는 기각**.
- 결과: **판 대부분 = T3 상비군, 후반 = 神 1기 강림.**

## 3. 비용 근거 (왜 3, 왜 사용자 초안 "10"이 아닌가)

영혼은 현재 **극희소**: 보스 보상 7종 중 `💀+1` 하나, 2장 중 1택 → 보스당 기대 ~0.5, 골드·치명타 등과 경쟁. 올인해도 **판당 2~3개**. → "10"이면 T4가 한 판에 사실상 불가능(⭐⭐ 목표·서사 절정 봉쇄).

**3 = "잘 굴린 한 판에 딱 1기"** 나오는 값. 기존 문서의 `FAMILY_SEED_COST=3`(영혼 비용 선례)과도 일관. **상수 1개 — 플레이 게이트에서 T4 빈도 보고 조정.** 영혼 수입은 이번에 안 건드림(스코프 최소).

## 4. 구현 지점

- `config.ts`: `TIER4_SYNTHESIS_SOUL_COST = 3`
- `GameState.synthesize()` T4 분기(`a.tier===3 && b.tier===3`): 세 번째 T3 확인 **후** 영혼 체크 → 부족 시 `pendingNotification` + `return null`; 성공(splice) 시 `enhancePoints -= COST`.
- 테스트: 영혼 부족 시 T4 미생성 / 충분 시 생성 + 차감.

## 5. 후속 (미착수)

- 만약 플레이에서 **T4 1기가 여전히 T3를 obsolete**시키면 → **B안(T4 동시 필드 상한 1)** 추가 검토. A는 "T4를 늦고 드물게", B는 "T4가 있어도 T3가 물량". 필요 시 결합.
- 12-F2 지배 시퀀스 재검증 대상(영혼이 이제 T4 게이트 = 새 병목).
