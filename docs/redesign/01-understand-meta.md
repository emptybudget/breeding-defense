# 메타게임/리텐션 구조 분석 보고

분석 파일: `src/game/MetaProgress.ts`, `src/game/config.ts`(META_UPGRADES/WORLD_CONFIGS), `src/scenes/StageSelectScene.ts`, `src/scenes/render/popups/{RewardPopup,SoulShopPopup,VictoryPopup,GameOverPopup}.ts`, 보조로 `GameScene.ts` 보석 흐름 확인.

## 1. 판과 판 사이 루프

**승리 시** (`VictoryPopup`): 💎+1 고정(`GameScene.ts:283`, 매 승리마다 반복 지급), 생존시간 기록 갱신 체크, 그리고 [다시하기 / 무한 모드 / 스테이지선택] 3버튼 + DPS 미터. **패배 시** (`GameOverPopup`): [다시하기 / 💎1개로 이어하기 / 📺광고 부활(판당 1회, 1.5초 시뮬) / 스테이지 선택] + DPS 미터.

**구조적 문제**: 판이 끝나도 "다음에 뭘 할지"를 제시하는 요소가 전무하다. 승리 팝업은 이번 판에서 뭘 발견했는지(도감), 다음 스테이지가 뭔지, 보석으로 뭘 살 수 있는지 아무것도 요약하지 않는다. 다음 판을 시작할 이유는 순전히 플레이어 내적 동기(기록 갱신, 도감 채우기)에 의존한다. 판 사이 유일한 "결정"은 StageSelectScene 하단의 영구 강화 구매인데, 이는 씬 하단에 수동적으로 나열될 뿐 "이번 판 보석으로 이걸 샀으니 다음 판이 더 쉬워진다"는 인과 연출이 없다. 루프의 뼈대(획득→투자→재도전)는 데이터상 존재하지만 **감정적으로 닫혀 있지 않다.**

## 2. 영구 진행 요소 전수 조사와 소진 시점

| 요소 | 내용 | 소진 시점 |
|---|---|---|
| 💎 보석 | 수입: 승리+1(무한 반복), 도감 마일스톤 6개(10/18/25종 → 1+2+3, 일회성), 인게임 보상카드 +1 | — |
| 메타 업그레이드 6종 | 총 비용 **14보석** (시작골드3 + 소환비용2 + 유닛한도2 + 자동골드2 + 2배속3 + 잭팟2) | **약 10~14승 = 1~2일이면 전부 MAX** |
| 도감 25종 | 첫 제작 기록 + 마일스톤 보석 | T4까지 며칠 걸릴 수 있으나 보상은 총 6보석뿐, 25종 후 종료 |
| 스테이지 기록 | 스테이지별 최고 생존시간. 승리시간이 고정이라 **무한 모드에서만 실질 의미** | 무기한이지만 표시가 9px 텍스트 한 줄 |
| 스테이지 해금 | `STAGE_UNLOCK_GEM_COST`는 레거시 — StageSelectScene은 `unlockStage`를 아예 호출하지 않음 | — |

**치명적 발견**: `isWorldUnlocked()`(StageSelectScene.ts:54-60)는 `DEV_UNLOCK_ALL_WORLDS` 없이는 **W1만 반환하고 W2/W3 해금 로직이 미구현**("For now just allow W1 always"). 프로덕션 빌드에서 플레이어는 튜토리얼 5판(합계 14분)만 접근 가능하다. 또 스테이지 그리드 내 개별 스테이지는 잠금 체크 없이 전부 클릭 가능 — W1-1을 깨기 전에 W1-5로 직행할 수 있다.

**소진 추정**: 해금 로직이 완성됐다고 가정해도 15스테이지 첫 클리어 = 순 플레이 약 84분, 재도전 포함 2~4시간. 메타 업그레이드 완주 14보석 ≈ 승리 14회. 도감 25종이 가장 긴 축이지만 이것도 집중 플레이 시 **2~4일이면 영구 진행이 전부 바닥난다.** 이후 보석은 소비처가 판당 소모품 2종(보상 선택지 확장 1개, 이어하기 1개)뿐인 잉여 화폐가 된다. 영혼(💀)은 GameState 소속 판내 화폐라 영구 축적이 없다.

## 3. 스테이지 15개 구조와 재플레이 동기

W1(2~4분, 기능 단계 해금 튜토리얼) → W2(7분×5, 보스 3페이즈+스크립트 웨이브) → W3(7분×5, 스폰 2800ms까지 압축+엘리트 30초). 파라미터 커브(fastRatio/tankRatio/bossHpMult 15→30/eliteInterval)는 잘 짜여 있고, GD2 위협 브리핑이 "빌드를 짜는" Plan 단계를 지원한다. 그러나 **재플레이 보상이 구조적으로 0에 수렴**한다: 재클리어 보상은 동일한 💎1, 스테이지별 별점/등급 없음, 조건부 도전과제 없음, 일일 변조(mutator) 없음. 무한 모드 기록이 유일한 재도전 훅인데 기록은 스테이지 선택 화면의 작은 텍스트로만 존재하고 랭킹·보상과 연결되지 않는다. 벤치마크인 히어로즈 랜덤 디펜스류의 "같은 스테이지를 다른 빌드로 다시" 동기를 받쳐줄 장치(빌드 제약 도전, 주간 시드 등)가 없다.

## 4. 세션 설계 vs 모바일 세션 패턴

W1의 2~4분은 이상적이지만, 본게임 W2/W3의 **7분 고정 + 팝업/보상 선택 포함 실질 8분+**는 대중교통·화장실·자기전 마이크로 세션(평균 3~5분)을 초과한다. 더 문제는 실패 비용의 비대칭: 6분 차에 40마리를 넘기면 6분이 통째로 증발하고, 완충 장치는 광고 부활 1회와 보석 이어하기뿐이다. 중단 저장(앱 전환 시 판 상태 보존)에 대한 코드가 이번 분석 범위에서 확인되지 않았고, 세로 한손 플레이 타깃과 달리 세션 길이는 "앉아서 하는 게임" 설계다. 2배속이 메타 **구매 항목**(3보석)이라 신규 유저의 첫 며칠 — 이탈이 가장 많은 구간 — 이 가장 느린 경험이라는 역설도 있다. 판을 5분 기본 + 보너스 연장 구조로 재편하거나 2배속을 기본 제공하는 방향 검토가 필요하다.

## 5. 수익화 표면

**현재 존재하는 훅 3개**: (1) 광고 부활 — 이미 UI/흐름 완성, SDK만 붙이면 됨. (2) 보석 이어하기 — 보석이 IAP 화폐가 되는 순간 유료 continue. (3) 보상 선택지 확장(💎1로 2→3장) — 좋은 소액 싱크. **그러나 보석 싱크 총량이 14 + 소모품뿐이라 보석 IAP는 현재 구매할 이유가 없는 죽은 상품**이다. 수익화가 성립하려면 싱크 확장이 선행돼야 한다: 영혼상점의 영구화(💀 이월 + 영구 트리), 도감 기반 스킨/변형, 잭팟 확률 부스트 등. 광고 슬롯 후보로는 승리 보석 2배, 판 시작 시 무료 소환 3회, 미니보스 보상 카드 리롤이 기존 시스템에 자연스럽게 붙는다. 일일 보상·미션·시즌 구조는 전무하므로 D1/D7 리텐션 장치는 사실상 도감 하나에 걸려 있다.

## 핵심 결론

경제 뼈대는 있으나 (a) W2/W3 해금 미구현으로 프로덕션 콘텐츠가 14분, (b) 영구 진행 총량이 2~4일 분량, (c) 재클리어 보상 부재, (d) 보석 싱크 고갈로 수익화 기반 부재, (e) 7분 세션이 모바일 패턴과 불일치 — 리텐션 위기는 UI 이전에 **메타 구조의 얕음**이 원인이다. 최우선 순위: 월드 해금 로직 구현 → 영혼의 영구화(두 번째 장기 화폐) → 스테이지별 조건부 도전(별 3개식) → 일일 변조 스테이지.
