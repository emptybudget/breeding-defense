## 9점 로드맵 — 잔여 갭 4개를 닫는 기획 (v1.1~v1.2, M5 이후)

> 헌법 제2조 준수: 각 항목에 "뺄 것/안 할 것" 명시. 우선순위 = 점수 상승폭 ÷ 개발비.

### G1 🥇 주간 시드 챌린지 + 익명 리더보드 — 소셜 3→7 / 볼륨 5.5→7 / 리텐션 6.5→8

- **주간 시드**: 매주 월요일, 전 유저가 **같은 소환 시드·같은 스테이지 변형**으로 경쟁. M3의 rng 주입 구조가 이미 시드 고정을 지원 — 콘텐츠 제작 없이 무한 재생성되는 엔드게임. 점수 = 무한 모드 생존 시간 + Gen 보너스.
- **리더보드**: Firebase 익명 인증 + Firestore 상위 100 + 내 순위. 서버 코드 0(보안 규칙만). 부정행위는 상위 100 수동 검토 수준으로 시작 — 완벽 방지는 안 함(뺄 것).
- 계보 공유 카드(BM 기획)에 "주간 N위" 뱃지 — 공유 동기 완성.
- 안 할 것: 실시간 PvP, 길드, 채팅 (전부 1인 개발 파산 코스).
- 개발비: 중. 선행: M5, Firebase Hosting 이미 사용 중.

### G2 🥇 적 로스터 3종 추가 — 의사결정 7.5→8.5 / 볼륨 +0.5

- 🛡 **실드**: 첫 N히트 무시 → 다타수(Blade_Hound류) 카운터 / 💢 **분열**: 사망 시 소형 2기 → 광역 카운터 / ✨ **힐러**: 주변 회복 → 저격(Falcon_Eye) 카운터.
- 의도: 스테이지 브리핑(GD2)의 "적 보고 빌드 짠다"(Plan 박자)가 실제로 성립하려면 **카운터 관계가 3개는 필요**. 현재 NORMAL/FAST/TANK는 전부 "DPS로 밀기"라 빌드 분기가 없음.
- W2·W3 스테이지 구성에 편입(신규 월드 제작 안 함 — 뺄 것). 스프라이트 3장(AM5 확장).
- 개발비: 중 (EnemyRenderer 확장 + 시뮬 재검증).

### G3 🥈 BGM 실자산 3트랙 — 사운드 6→8

- Suno류 AI 음원: ①탐색(라운드 1~9, 아르누보 왈츠 톤) ②서지(10~13, 스트링 상승) ③보스/OVERTIME. 크로스페이드 전환은 기존 SoundManager 게인 노드 재사용.
- 안 할 것: 유닛별 보이스(U11), 동적 레이어링(스템 믹싱) — 전부 v1.2 이후.
- 개발비: 소 (생성·선별은 사용자, 통합은 반나절).

### G4 🥈 GD4 일일 도전 + GD5 누적 과제 승격 — 리텐션 확정타

- 이미 기획 완료(기존 로드맵), v1.1 → **출시 주 패치로 승격**. 근거: 리텐션 6.5는 D7에서 무너지는 수치, 유물 알 수급(BM)도 GD4에 의존.
- 개발비: 중 (기존 기획 그대로).

### G5 🥉 클라우드 세이브 — 안정성 8→9, 전손 방지

- Firebase 익명 인증 + 가문·메타 스냅샷 백업(G1과 인프라 공유). 기기 변경 = 코드 입력 복원.
- 안 할 것: 계정 시스템·소셜 로그인 (Capacitor 스토어 로그인으로 추후 대체).
