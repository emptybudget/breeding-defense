# 34 — T3 운용성 (B: 역할 표면화 + D: T3-only 승리 검증)

> 확정: 2026-07-13 (사용자 결정 B+D, Fable 5). 원천 문제: 32번(영혼 촉매)은 "T4 조기 강림"을 고쳤지만, 사용자 체감 **"T3를 잘 쓰는 방법을 모르겠다"는 별개 문제** — T3에서 플레이어가 내릴 결정이 없음.

## 1. 진단 — T3는 시스템 진공지대

| 티어 | 붙어있는 시스템 |
|---|---|
| T1 | 교배(Gen)·영혼 강화(+5)·소환 |
| T2 | 영혼 강화(+3)·특성 12종·기믹 다수 |
| **T3** | **없음** — 교배 불가(`canBreed` tier1 한정), 강화 트랙 없음, 6종 중 3종(Dino/Griffin/Wizard) 기믹 0 |
| T4 | 영혼 촉매·서사 절정·체인 라이트닝 |

4겹 원인:
1. **고르는 게 아니라 '되는' 것** — 특정 T3 = 특정 T2 2종 = 특정 T1 4종, 소환은 랜덤 → 빌드 선언 불가.
2. **역할이 코드에만 있고 안 보임** — §2 표가 게임 어디에도 노출 안 됨.
3. **T4 레시피의 암묵 2계급** — Wizard/Griffin/Hawk="바칠 재료", Dino/Shaman/Artillery="남길 상비군". 제물 서사로서 좋은 긴장인데 레시피북 암기 없이는 비가시.
4. **미검증 균형** — Phase C 보스 HP(`BOSS_HP_PHASE_C_SCALAR` 65/15)는 "Gen3 **T4** 처치 3.3s" 기준 튜닝. 32번 이후 판 대부분이 T3 상비군인데 **T4 0기 승리 가능성은 아무도 검증 안 함**.
