# 비즈니스 모델 설계 (v1.1 이후 투입)

> 2026-07-06 확정. 투입 시점: **M5 + 출시 후 데이터 관찰 뒤** (BM 마일스톤은 코어 로드맵과 분리).
> 대원칙 3개가 모든 결정에 우선한다.

## 0. 대원칙

1. **"뽑지 말고 낳아라"와 충돌 금지** — 캐릭터 뽑기 금지. 모든 확률형 획득은 **부화(hatching)** 언어로 포장한다. 스토어 문구에 "가챠" 대신 "부화".
2. **PvE 밸런스 비침범** — 유료 확률형 내용물은 **코스메틱 + 편의**까지만. 전투력 직결(데미지·Gen·변이 확률 영구 증가)은 유료 확률 상자에 절대 넣지 않는다 (추후 점수 경쟁 도입 대비 + 리뷰 방어).
3. **잭팟의 주인공은 인게임** — 최고 도파민은 여전히 무료 플레이의 전설 변이 부화다. 메타 뽑기 연출이 인게임 연출을 넘지 않는다 (볼륨·화려함 모두).

## 1. 화폐 구조 (기존 유지 + 1종 신설)

| 화폐 | 획득 | 소비 | 성격 |
|---|---|---|---|
| 골드 | 판 내 | 판 내 | 런 화폐 (불변) |
| 💀 영혼 | 판 내 보스 | 판 내 강화 + 가문 시드(3) | 런→메타 다리 (불변) |
| 💎 보석 | 승리·도감·도전과제 | 메타 트리·이어하기 | 무료 메타 화폐. **유료 판매 안 함** (아래 참조) |
| 🥚 **유물 알 (신설)** | 일일도전·과제·광고·IAP | 옛 가문의 부화당에서 부화 | **확률형 획득 전용** 화폐 |

**💎를 유료 판매하지 않는 이유:** 보석은 이어하기·메타트리 등 전투 편의와 닿아 있어 유료화하면 원칙 2가 뚫린다. 유료 확률 경제는 유물 알로 완전 격리 — 확률 규제 대응도 화폐 1종만 관리하면 된다.

## 2. 확률형 코어 — "옛 가문의 부화당" (유물 알 시스템)

**콘셉트:** 몰락한 옛 명가들이 남긴 알을 부화시켜 **그 가문의 유산(코스메틱·칭호·문장)** 을 계승한다. 뽑기 UI가 아니라 **둥지 UI 재사용** — M4에서 만든 부화 연출(알 3초→등급 플래시→카드)이 그대로 뽑기 연출이 된다. **신규 연출 개발비 0.**

### 내용물 풀 (전부 비전투)

| 등급 | 확률 | 내용물 |
|---|---|---|
| 일반 | **80%** | 유닛 팔레트 스킨(계열 리컬러), 부화 이펙트 색 변형, 골드 소액(200G 상당 아님 — 다음 판 시작 +50G 1회권) |
| 희귀 | **17%** | 유닛 코스튬 스킨(NovelAI 변주 — 파이프라인 재활용), 희귀 칭호(네이밍 풀 확장: '옛왕조의' 등), 가문 문장 장식 프레임 |
| 전설 | **3%** | 정점 유닛 전용 스킨(T4 외형 교체), 전설 칭호, **몰락 가문 시나리오 카드**(혈통서에 꽂히는 스토리 1장 + 전용 문장) |

- **천장(피티): 40회** 무전설 시 다음 전설 확정, 카운터 UI 상시 노출. 중복 획득 = 파편 전환(파편 N개→원하는 스킨 교환) — 중복 불쾌감 차단.
- **확률 공시**: 부화당 화면 안에서 1탭 열람 (2024.3 시행 확률형 아이템 정보공개 의무 — 한국 출시 필수). 등급·개별 아이템 확률 전부 표기.
- 인게임 전설 변이(0.5~1%)보다 부화당 전설(3%)이 후하다 — **게임플레이 잭팟이 더 희귀하고 더 화려**해야 하므로 (원칙 3), 연출 위계는 인게임 > 부화당 유지.

### 유물 알 수급 (F2P 일일 루프)

| 소스 | 수량 | 비고 |
|---|---|---|
| 일일 도전(GD4) 클리어 | 1개/일 | GD4를 v1.1 필수로 승격하는 근거 |
| 보상형 광고 | 1개/일 | 아래 광고 §3 |
| 누적 도전과제(GD5) | 총 ~15개 | 일회성 |
| IAP | §4 | — |

F2P 기준 **주 14개 → 월 ~60회 부화** = 천장 1.5회/월. 수집 완주는 수개월 — 시즌 추가분으로 연장.

## 3. 광고 설계 (보상형 온리 — 강제 전면·배너 금지)

| 슬롯 | 보상 | 위치 | 빈도 |
|---|---|---|---|
| 부활 (기존) | 이어하기 | GameOver | 1회/판 |
| 승리 2배 | 💎 +1 → +2 | Victory | 1회/판 |
| 카드 리롤 | 보스 보상 카드 1회 리롤 | 보상 팝업 | 1회/판 |
| 유물 알 | 🥚 +1 | 부화당 | 1회/일 |
| 혈통 축복 | **전설 변이 +0.5% (24h)** | 부화당/메인 | 1회/일 |

- 혈통 축복만 전투 관련이지만 **시한부 +0.5%p** — 영구 아님 + 무료(광고)라 원칙 2 통과. v3 BM 노트 그대로.
- 전면 광고 금지 이유: 7분 세션 게임에서 판 사이 전면광고는 Loop 박자를 죽인다 — 리텐션 > eCPM.

## 4. IAP 카탈로그 (₩ 기준)

| 상품 | 가격 | 내용 | 노림수 |
|---|---|---|---|
| **광고 제거** | ₩5,900 | 광고 슬롯 5종의 보상은 그대로, 시청만 스킵 (자동 수령) | 헤비유저 1차 전환. "보상 유지"가 핵심 — 광고 제거가 손해가 되면 안 팔림 |
| 스타터 명가 팩 (1회) | ₩3,300 | 🥚10 + 가문 슬롯 +1 + 전용 칭호 '개국공신' | 첫 결제 장벽 붕괴용 최저가 |
| 유물 알 10+1 | ₩11,000 | 🥚11 | 기본 벌크 |
| 가문 슬롯 +2 | ₩4,400 | 혈통서 슬롯 확장 (기본 3→5) | 수집가 대상, 비확률 확정 상품 |
| **혈통 패스 (시즌 4주)** | ₩7,900 | 무료트랙: 🥚4+💀부스트 / 유료트랙: 🥚12+시즌 한정 T4 스킨+칭호 | 시즌제 리텐션 축. 한정 스킨 = FOMO는 코스메틱까지만 |

- 가격 앵커: 광고 제거 < 패스 < 10연 — 소액 3종이 주력 (하이퍼캐주얼 인접 유저층).
- 월정액(구독)은 보류 — DAU 데이터 없이 설계하면 손해.

## 5. 매출 시나리오 (보수적)

- 주 수익원 예상: **보상형 광고 55% / 광고제거+스타터 25% / 패스·알 20%** (소규모 인디 PvE 통례).
- 광고 5슬롯 × 완주율 40% × eCPM $8~15 기준 DAU 1,000명 ≈ 월 $400~700 — 손익보다 **전환 퍼널 학습**이 1차 목표.
- 핵심 KPI: D1/D7 리텐션 → 광고 완주율 → 광고제거 전환율(목표 2~3%) → 패스 전환율. 이 순서로만 최적화.
