## 2. 비전

**한 줄 피치**: "뽑는 게임이 아니라 낳는 게임 — 당신이 직접 교배로 길러낸 5세대 혈통이 신(神)을 낳는, 유일한 랜덤 디펜스."

**디자인 필러 3개**
1. **혈통이 심장이다** — 교배는 세대·특성·변이를 굴리는 능동 도박. 소환(랜덤)·합성(질서)·교배(카오스)의 삼각 축.
2. **팔리는 몸 위에서** — 모든 신규 시스템은 44pt·엄지존·낙차 연출을 갖춘 모바일 네이티브 쉘 위에 올린다. 스샷 5장 전부 교체 가능한 상태가 기준선.
3. **판이 이어진다** — "이번 판은 지난 판의 자식". 가문 계승·영혼 이월로 D7까지 지탱하는 "오늘 켤 이유"를 만든다.

## 3. 시스템 재설계

Phase 0(B 쉘) → Phase 1~2(A 골격) → Phase 3(A 메타) → v1.1(C 이식) 순.

### R1. JuicyButton 리스킨 + 한손 커맨드 독 — P3
- 공용 `JuicyButton` 1개(Graphics: 라운드 8px+2px 금테+음영, 눌림 scale 0.94/80ms+햅틱, primary/secondary/danger)로 45버튼 일괄 치환. 폰트 monospace → WebFont 1종(서브셋)+숫자 비트맵폰트.
- 조작을 하단 92px 독으로: 중앙 소환 96×64px(비용 뱃지), 좌 한도+1, 우 영혼상점 각 56×48. ⏸ 등 저빈도는 우상단 48×48 스택. 전 버튼 히트영역 ≥48px, `pointerup`+슬롭 8px. 판매존은 시각=판정 동일 상수, 드래그 시 독이 판매 모드로 변신.
- **재활용도: 상** — artnouveau.ts 금테 문법 확장, 로직 무변경 렌더 레이어만.

### R2. 라운드 언어 + 소환 낙차 연출 — P5·P4
- 30초 보스 박동을 "ROUND n" 명명(7분=14라운드). 상단 핍 14개(보스 라운드는 해골 핍), 라운드 시작 배너 0.6s, 클리어 시 "+5G" 스탬프(유일한 밸런스 수치 변경, 총 +70G/판, 폴백 스위치 유지). GameOver를 "라운드 9 도달 — 최고기록 11"로 — 자랑 단위 확보.
- 소환/교배 출산 공통 카드 뒤집기 0.35s: 일반=흰 플래시 / 변이=보라 빔+배너 / 잭팟 T2(4%)=금 빔. 확률 무변경.
- **재활용도: 상** — G4 웨이브 스케줄·배너 파이프라인 재조립.

### R3. FTUE 5스텝 + 패배 학습 + 첫 세션 Pop 예고 — P5·P4
- 19줄 텍스트 덮개 **폐기**. W1 해금 뼈대 위 스포트라이트+손가락 고스트+강제 1회 수행 스텝(W1-1 3스텝, 이후 신기능당 1스텝, 재입장 시 스킵). 발견 불가 인터랙션 8종 전수 커버.
- 적 한계를 32px 카운트 링(n/40, 32부터 붉은 맥동+햅틱)으로 승격, GameOver 1행에 "패배 원인: 적 40마리 초과"+팁 1줄.
- **2배속 W1 무료 기본화**(💎3 상품은 W2+ 문구로 후퇴 — 수익 표면 감소를 감수하는 올바른 결정), W1-5 클리어 시 T4 시네마틱 컷인(NovelAI 풀스크린 1장, "당신이 낳게 될 신" 2.5s), 승리 카드 CTA가 다음 해금 1개 지목.
- **재활용도: 중** — features 해금 로직 무변경, TutorialPopup 교체.

### R4. 혈통 세대(Gen) 시스템 — P1·P2
- `gen: 0~5` 필드. 소환=Gen0, 교배 자식=`max(부모 Gen)+1`. Gen당 공격력·공속 **+8%**(상한 +40%). Gen은 교배로만 상승.
- 합성은 재료 Gen **평균(내림)** 계승 → 최종 목표가 "T4"에서 "**Gen4+ T4**"로 확장.
- 자식 이름 자동 생성(부모 음절 조합, 화이트리스트 200개, 실패 시 "종명+세대" 폴백). Gen2+만 10px 이름표.
- **재활용도: 중** — UnitData 확장+교배/합성 로직 수정, 렌더는 이름표 1종.

### R5. 특성 1슬롯 상속 — P1
- T2 기믹 12종을 `trait` 데이터로 승격. T1은 슬롯 1개(기본 빈칸). 상속: 한쪽 보유 **50%** / 양쪽 각 **40%**+**20%** 제3 무작위(잡종 강세). 합성 시 재료 특성 1개 **60%** 계승. T1 6종×특성 12종=72 표현형.
- **재활용도: 상** — 기믹 로직 12종 기존 코드, 바인딩만 데이터화(U4 가시성 패스 동시 해결).

### R6. 변이 3등급 잭팟 — P4·P1
- 변이 15%를 총확률 동일하게 분해: 일반 **12%** / 희귀 **2.5%**(Gen+2 점프) / 전설 **0.5%**(특성 2슬롯+금빛 이름). 부화 0.4s 프리즈→등급색 플래시(백/청/금)→셰이크 200/350/500ms+배너+햅틱 3/4/5단. R2의 카드 연출과 동일 파이프라인. 전설은 도감·결과 카드 영구 기록.
- **재활용도: 상** — 수치 재배분+기존 주스 조립.

### R7. 둥지 UI — P1·P3·P5
- "같은 카테고리 2마리 겹치기" **폐기**. 하단 독 위 둥지 패널(높이 88px, 슬롯 2개 56×56px) 상시. 드래그 투입→2슬롯 차면 **예상 혈통 카드**(자식 Gen·특성 상속%·변이% — 숫자 3개 상한, 기대치 공시라 기각된 '미리보기 고스트'와 무관, 합성엔 미적용)→교배 버튼 64×48 탭→3초 알 게이지→부화. W1-2에서 금빛 펄스로 자가 발견.
- **재활용도: 중** — 교배 판정 재사용, 패널 신규(artnouveau 금테).

### R8. 가문 계승 메타 — P2
- 판 종료 시(승패 무관) 최고 Gen 유닛 1마리를 "가문"으로 도감 등록(종·Gen·특성·이름·탄생 스테이지). 다음 판 이월 💀로 가문 알 구매(Gen1=💀3, Gen2=💀8, **상한 Gen2 고정** — 심사에서 상한+1 트리 기각). 영혼상점 2차 트리: 특성 상속률 +5% / 희귀 변이 +0.5% (2종으로 축소).
- C의 방주 대신 가문 채택 사유: 영구 사망 없이 같은 P2를 풀며 손실 회피 리스크 0.
- **재활용도: 중** — 도감·영혼상점·저장 구조 확장.

### R9. (v1.1 예비) 야생 인자 — C 이식
- ELITE/보스 한정 희귀 인자 1~2종을 **처치 드랍**으로 도입(그물·1.2초 유예창 제거 — 실시간 튜닝 의존 회피), 교배 재료로 사용. 라운드 배너에 인자 예보. D7·과금 지표 확인 후 착수. 본 기획서 범위 밖.

### 빼는 결정 (더하기만 하지 않는다)
1. 겹치기 교배 인터랙션 폐기(R7로 대체). 2. 19줄 텍스트 튜토리얼 폐기. 3. W1 2배속 💎3 상품 후퇴. 4. 이모지 60+곳 → 20 이하(재화→적→기타 순). 5. C의 그물 포획·영구 사망 기각. 6. B-M5 전면 리스킨 일괄 투입 기각 — 화면별로 M1~M5에 분산. 7. 가문 알 Gen 상한 확장 트리 기각(스노우볼 방지).

- 포함: R4+R5+R6의 데이터·판정부(gen/trait/이름 필드, 교배·합성 계승 규칙, 변이 3등급 판정). 렌더 무변경.
- 완료 판정: **순수 TS 유닛 테스트 — 상속 확률·Gen 전파·등급 분포 1만회 시뮬 오차 ±1%p** + `npm run build`. 하위 AI 모델이 브라우저 없이 자가 검증 가능한 이상적 단위.
- **게이트**: 사용자 W2-5 풀플레이 1회 — 기존 플레이 회귀 없음(혈통은 로그로만 확인).

### M4. 혈통의 무대 — 둥지·잭팟·가시화 (난이도: 중)
- 포함: R7(둥지 패널+예상 혈통 카드)+R6 연출부(3등급 부화)+이름표+GameOver 혈통 카드+혈통서 탭.
- 완료 판정: 빌드 통과 / 알 3장 등 자산 적용 / 결과 카드에 혈통 정보 4개 상한 렌더.
- **게이트**: 사용자 플레이 — "설명 없이 둥지로 교배를 발견할 수 있는가" + 잭팟 순간 체감 보고.

### M5. 가문 계승 + 밸런스 패스 + 잔여 리스킨 (난이도: 대)
- 포함: R8(가문 등록/출전·영혼 이월·2차 트리 2종)+타이틀/3탭/도감 카드 리스킨+NovelAI 잔여 자산+이모지 20 이하.
- 완료 판정: 2판 연속 플레이에서 1판 혈통이 2판 시작에 등장(저장 왕복 테스트) / 이모지 사용처 grep ≤20 / 스토어 스샷 5장 신규 촬영 가능 상태.
- **게이트**: 사용자 W2-5 풀플레이 — T4 완성 4~5분 유지 + Gen3+ 달성 + "T4 살짝 부족" 긴장감 보존 여부 보고. 필요 시 Gen 커브·상속률 재조정 루프.
