# 재설계 기획서 v3

> v2 대비 변경 핵심: ① 교배에 **계열 상성 규칙** 도입 — 부모 조합이 결과를 바꾸는 유일한 결정 축, 지배 시퀀스 유일성 검사를 시뮬 실패 조건으로 추가, ② **혈통 정체성 승계** — 융합 결과물이 시조의 이름·계열 문장을 물려받고 가문 기록이 '계보 체인'이 됨, ③ M1을 M1a/M1b로 분할해 로직 수술과 쉘을 분리, ④ 수직 예산을 **세이프존 포함으로 전면 재산정**(44/468/88).

## 2. 비전

**한 줄 피치**: "뽑는 게임이 아니라 낳는 게임 — 당신이 교배로 길러낸 혈통이 신(神)을 낳는, 유일한 랜덤 디펜스."

**디자인 필러 3개**
1. **혈통은 눈으로 보인다** — Gen은 스탯 시트가 아니라 화면 위의 형태(장식·크기·금색 일격)다.
2. **팔리는 몸 위에서** — 44pt·엄지존·세이프존을 지킨 모바일 쉘. 스샷 5장 전부 교체 가능이 기준선.
3. **판마다 다른 이야기가 남는다** — 시조의 이름이 신에게 새겨지고, 계보 체인이 혈통서에 쌓인다.

## 3. 시스템 재설계

### R1. JuicyButton 리스킨 + 한손 커맨드 독 — P3 【세이프존 재산정】
- 공용 `JuicyButton`(라운드 8px+금테+음영, 눌림 scale 0.94/80ms+햅틱)으로 45버튼 치환. 히트영역 48px 미만 지정 시 clamp(개발 빌드 throw). 폰트 WebFont 1종 서브셋.
- **수직 예산 — MOBILE_SAFE_ZONE_TOP=24/BOTTOM=16 포함 재산정**: 상단 바 **y24~68(44px)** / 필드 y68~536(468px) / 독 **y536~624(88px)**. 트랙(y90~520)·배치존·사거리 무변경. 적/유닛 스프라이트 최대 반높이 16px 기준 최저점 y536 = 독 상단과 경계 일치, 겹침 0(독은 불투명 패널, 터치 판정 독 우선). **이 산술을 config 상수 기반 순수 TS 테스트로 고정**(크롬이 세이프존 침범 시·트랙+반높이와 교차 시 실패). 스프라이트 반높이 ≤16px도 상수 테스트로 강제.
- 독(88px) 구성: 중앙 소환 96×64(비용 뱃지), 좌 한도+1, 우 영혼상점 56×48. 전 버튼 `pointerup`+슬롭 8px.
- **상단 바 폭 예산표(⏸ 정식 포함)**: 세그먼트 바 60 + "9/14" 28 + 타이머 40 + 링 32 + 재화 칩 2×44 + **⏸ 44×44** + 간격 7×8 = **348px ≤ 360**. ⏸는 바 높이 44와 동일 — 삐져나옴 없음.
- **드래그 컨텍스트 모드**: 유닛 드래그 시작 시 독 변신 — 중앙 둥지 슬롯 2개(56×56), 판매 존은 좌우 가장자리(각 48px, 시각=판정 동일 상수). **드래그 스펙 명문화**: 드래그 스프라이트 -40px 상향 오프셋(손가락 가림 해소), 슬롯 근접 시 스냅+하이라이트, **존 밖 드롭=원위치 취소(아무 일도 안 일어남)**. Gen1+/특성 유닛 판매는 0.3s 홀드 게이지(활성화는 M3, §6).
- 드래그 대안: 유닛 탭 → 바텀시트 **'둥지로'+'판매'** 버튼 2탭 경로 — 판매도 드래그 전용에서 해방.
- 오버레이 세이프존: 배너·예상 혈통 카드·부화 연출은 y100~420, 중앙 폭 320px.

### R2. 라운드 언어 + 소환 낙차 연출 — P5·P4
- 30초 보스 박동을 "ROUND n" 명명(14라운드). 세그먼트 바+숫자, 라운드 배너 0.6s, 클리어 "+5G" 스탬프(총 +70G). GameOver "라운드 9 도달 — 최고기록 11".
- 소환/부화 공통 카드 뒤집기 0.35s: 일반=흰 플래시, **금색은 혈통(Gen·희귀 변이 이상) 전용으로 독점** — 기존 주스의 금색 사용을 전수 감사해 치환(M4). T2 잭팟은 백금 플래시.

### R3. FTUE + 패배 학습 + 첫 세션 Pop — P5·P4
- 19줄 덮개 폐기. 스포트라이트+손가락 고스트+강제 1회 수행, 마일스톤별 분산 제작. **FTUE 스텝 진행 중에는 게임 속도를 1배속으로 강제 하향**.
- 적 한계 32px 카운트 링(32부터 붉은 맥동+햅틱), GameOver 1행 "패배 원인: 적 40마리 초과"+팁.
- 2배속 W1 무료 기본화. W1-5 클리어 시 T4 컷인.
- **첫 세션 확정 잭팟**: W1-2 최초 1회 교배는 희귀 변이 확정 롤. 희귀=Gen 한 계단 추가(R6)이므로 산출은 **Gen2** — 세션 목표(Gen3)를 선지급하지 않고 사다리 학습을 보존. 직후 FTUE 스텝 1개: "방금은 희귀! 보통은 한 세대씩 오른다."
- **교배 슬로모**: 둥지 2슬롯 충족~교배 확정 구간은 바텀시트와 동일한 0.3배속 — 예상 혈통 카드를 읽을 시간 창 보장.

### R4. 혈통 세대 + 계열 상성 — P1·P2 【전면 개정: 부모 조합이 결과를 바꾼다】
- `gen: 0~4`. 소환=Gen0. **교배는 부모 2마리 소모**, 알 3초, **판당 예산 6회**.
- **T1 6종을 3계열×2종으로 분류**(계열명·매핑은 M3 데이터로 확정). 교배 규칙 2행:
  - **동계열 교배**: 자식 Gen=max(부모)+1, 종=부모 중 무작위, 변이 15% — 사다리 경로.
  - **이계열 교배**: 자식 Gen=max(부모) 유지, 종=부모 중 무작위, **변이 확률 2배(30%: 일반 24/희귀 5/전설 1)** — 도박 경로.
- 결과: 두 번째 부모가 "아무 Gen0"일 수 없다 — Gen업에는 **같은 계열** 재료가 필요하다. Gen3 사다리는 교배 3회+동계열 Gen0 4마리인데 소환이 균등 무작위이므로 **어느 계열이 먼저 모이는지가 판마다 다르고**, 남는 타계열 유닛을 도박 재료로 태울지 합성 재료로 지킬지가 예산 6회의 배분 결정이 된다. 판마다 "이번 판의 혈통 계열"을 소환 결과가 정한다.
- **Gen의 전투 표현은 형태 변화**(오라 겹수 폐기): Gen1=금빛 오라 링 / Gen2=오라+**머리 장식(Graphics 뿔)**+혈통 일격(공격 4회당 금색 추가 발사체) / Gen3=장식이 왕관으로+스케일 1.10+일격 3회당 / Gen4=왕관 맥동+스케일 1.18+일격 2회당. 뒷면 수치: 일격=해당 공격 데미지 100% 추가타(Gen2 +25%~Gen4 +50% DPS).
- **합성은 재료 중 최대 Gen 계승**(합성 UI에 "Gen0+Gen3→Gen3" 사전 표기). 질서 축은 Gen을 보존만 하고, 교배만이 올린다.
- **세션 목표: Gen3 T4**. 산술: 동계열 3회(G0+G0→G1, G1+G0→G2, G2+G0→G3)+동계열 G0 4마리, 알 9초+드래그 6회 ≈ 40초. 예산 6회 중 3회는 이계열 도박/제2 사다리용.
- **M3 시뮬에 '지배 시퀀스 유일성 검사' 추가(§6)**: 소환 시드 100종에서 최적 사다리 계열이 시드에 따라 달라지고, 예산 내 Gen3 도달 전략이 2개 이상(순수 사다리/도박 혼합) 존재해야 통과. **지배 시퀀스가 유일하면 실패.**

### R4b. 혈통 정체성 승계 — P1·P2 【신설: 애착 대상의 보존】
- 교배 자식마다 **자동 생성 혈통명**(시조 종 이름+세대 접미) 부여, 판 내 **계보 체인**(부모→자식 링크) 기록.
- **융합(합성)은 최대 Gen 재료의 혈통 ID를 승계** — 결과물 이름이 "〈혈통명〉의 〈유닛명〉"이 되고, 변이 마크·계열이 따라간다. **정점 유닛(필드 내 최대 Gen 혈통 계승자 1마리)에는 계열 문장 오버레이(Graphics 3종) 표시** — 최종 T4의 얼굴이 계열×시조×변이 마크로 판마다 다르다.
- 이름·전체 계보는 탭 바텀시트에서 노출(필드 이름표 없음 유지).

### R5. 특성 1슬롯 상속 — P1
- T2 기믹 12종을 `trait`로 승격, T1 슬롯 1개. 상속 50%/40%+제3 무작위 20%, 합성 60% 계승. 해금 W2-1 이연. 첫 세션 예상 혈통 카드는 숫자 2개(Gen·변이%) — 이계열 조합 시 변이%가 30%로 바뀌어 표시되므로 **카드가 매번 같지 않다**.

### R6. 변이 3등급 잭팟 — P4·P1
- 기본 15%(이계열 30%) 분해: 일반 12%(24) / 희귀 2.5%(5) / 전설 0.5%(1).
- **희귀=자식 Gen 한 계단 추가(+1)** — Gen+2 폐기(사다리 스킵 방지). 전설=특성 2슬롯+금빛 이름.
- **일반 변이 즉시 소보상**: 합성 와일드카드 + **+10G 스탬프 + 도감 신규 변이 기록 팡파레** — '꽝 아님'이 아니라 체감 보상. 이계열 도박(희귀 5%)이 첫 세션 이후 가뭄 구간의 중간 낙차 이벤트를 판당 1회 이상 공급.
- 소프트 피티: 8회 무희귀 시 10%(발동 후 리셋). 전설 계정 누적 60회 피티(영속 저장 M3).

### R7. 둥지 — P1·P3·P5
- 겹치기 교배 폐기(제거 시점 M1b, §6). 둥지는 드래그 컨텍스트 모드 안에 산다. 평시 크롬 상단 44+독 88=132px.
- 슬롯 1 투입 시 독에 24px 접힘 탭(알 실루엣+금빛 펄스), 2슬롯 차면 예상 혈통 카드(세이프존 내, 0.3배속)→교배 버튼 64×48→3초 알→부화.

### R8. 가문 계승 메타 — P2 【가문 알 폐기】
- 판 종료 시 **계보 체인을 통째로 '가문'에 등록**(시조→교배 단계→융합 결과, 노드별 종·Gen·변이 마크·이름) — 혈통서는 체인 카드 목록. 정점이 매판 같은 T4여도 체인은 판마다 다르다.
- **가문 알(Gen2 시작) 폐기 → 가문 시드(💀3)**: 등록 가문의 시조 종 Gen0+특성 1개 시드로 출전 — 계열 확보와 특성 축의 지름길이지 **Gen 지름길이 아니다**. 세션 목표 Gen3의 긴장 불변.
- 2차 트리 2종: 특성 상속률 +5% / 희귀 변이 +0.5%.

## 6. 마일스톤 로드맵 (각 M 끝 사용자 플레이테스트 게이트)

### M1a. 제품 쉘 — 게임 로직 무변경 (난이도: 소~중)
- 포함: JuicyButton 45버튼 치환+세이프존 포함 HUD 재배치(바 y24~68/독 y536~624)+카운트 링. 겹치기 교배·기존 드래그 판매는 **이 시점 그대로 존치**.
- 완료 판정: `npm run build` / Text버튼 grep 0건(**범위: popups/·HudRenderer 등 UI 버튼 생성부 한정, 허용 목록: UnitRenderer 유닛 인터랙션·팝업 배경 흡수 레이어**) / clamp 유닛 테스트 / **크롬-세이프존-트랙 산술 순수 TS 테스트**(스프라이트 반높이 ≤16px 포함).
- 게이트: 한손 조작감, 오발 소멸, 홈 인디케이터 영역 오터치 없음.

### M1b. 드래그 컨텍스트 모드 (난이도: 중)
- 포함: 독 변신(둥지 슬롯 2·가장자리 판매존)+드래그 스펙(-40px 오프셋·스냅 하이라이트·존 밖 드롭=취소)+바텀시트 '둥지로'/'판매' 2탭 경로. **슬롯은 기존 `GameState.startBreeding`에 임시 배선(구 85/15, 부모 비소모), 겹치기 경로는 이때 제거.** 홀드 확인은 스텁(항상 off) — 완료 판정은 M3로 이동.
- 완료 판정: 빌드 / 판매존 시각=판정 동일 상수 / 겹치기 코드 제거 grep.
- 게이트: "필드 최상단 유닛을 한손으로 둥지 투입" + **"존 밖 오드롭 시 아무 일도 안 일어남"** + 오판매 소멸.

### M2. 리듬과 낙차 (난이도: 중)
- 선결(타임박스 2일): 프리징 계측(워치독+링버퍼→오버레이 덤프)만. '해결'은 소킹 기준(연속 10판 무재현), 병렬 트랙.
- 포함: R2+R3(현존 인터랙션 FTUE·패배 사인·2배속 무료·T4 컷인). **gameSpeed2x 기구매자 3💎 환불 마이그레이션 포함.**
- 완료 판정: 라운드 경계·+70G·연출 분기 유닛 테스트 / 환불 마이그레이션 테스트 / GameOver 원인 문구.
- 게이트: "죽은 이유를 팝업만 보고 말할 수 있는가".

### M3. 혈통 데이터층 (난이도: 중~대)
- 포함: R4+R4b 데이터+R5+R6 판정부(gen/trait/계열/혈통 ID·계보 체인, max 계승, 부모 소모, 예산 6회, 피티, 와일드카드)+홀드 확인 활성화(M1b 스텁 해제). **혈통 일격 데미지 로직은 순수 TS 테스트 대상이되 런타임 플래그 off**(M4에서 연출과 함께 활성화). **세이브 스키마 버전 필드+마이그레이션 함수+구버전 세이브 로드 순수 TS 테스트**(전설 피티 60회 영속 포함).
- 완료 판정: 상속·Gen 전파·계열 규칙·피티 테스트 / **등급 분포 시뮬 10만회, 허용 오차 ±3σ, 피티 비활성 모드**(피티 발동·리셋은 별도 테스트) / 7분 행동 예산 시나리오(교배 6회·부모 소모·알 3초 하에 Gen3 T4 시퀀스 존재) / **지배 시퀀스 유일성 검사: 시드 100종에서 최적 계열이 가변이고 전략 2개 이상 — 유일하면 실패** / 빌드.
- 게이트: W2-5 풀플레이 회귀 없음(일격 off라 DPS 불변 — 눈 판별 가능).

### M4. 혈통의 무대 (난이도: 중)
- 포함: R7 완성+예상 혈통 카드(0.3배속 슬로모)+R6 연출부(일반 변이 +10G·팡파레)+혈통 일격 플래그 on+W1-2 확정 희귀(Gen2 산출)+후속 FTUE 스텝+**금색 전수 감사(혈통 전용화)**+형태 기반 Gen 표기+결과 카드+교배 FTUE(최초·유일 제작).

- 게이트: "설명 없이 둥지 발견" + 첫 세션 잭팟 체감 + **"전투 최고조 스크린샷 1장에서 Gen 단계를 오답 없이 지목"**.

## 7. 리스크 레지스터 + 비즈니스 모델 노트

| 리스크 | 심각도 | 완화책 |
|---|---|---|
| 계열 규칙이 소환 운빨 답답함 유발(동계열 4마리 미확보) | 높음 | 계열 3개 중 택1이라 기대 소환 수 낮음, 이계열 도박·가문 시드가 보조 경로, M3 시뮬로 도달률 검증 |
| 프리징 버그 장기화 | 높음 | 타임박스 계측+소킹 판정, 병렬 트랙 |
| 혈통 일격(+50%)이 긴장감 파괴 | 높음 | 주기 파라미터 1개 튜닝, M5 게이트 재측정 |
| 혈통 유닛 오판매 | 높음 | 홀드 확인(M3)+가장자리 판매존+존 밖 드롭 취소+바텀시트 판매 |
| FTUE 과부하 | 중 | 특성 W2 이연, 카드 숫자 2→3 점증, 슬로모·1배속 창, M별 분산 |
| 계보 체인 저장 비대화 | 중 | 판당 체인 노드 ≤8, 가문 슬롯 상한 |
| 교배 예산 6회 답답함 | 저 | 상수 1개, M4 게이트에서 8회 확장 여지 |

**비즈니스 모델 노트**: ASO "출산에서 최강 유닛이 나오는 유일한 랜덤 디펜스". 첫 세션 확정 희귀=스토어 영상 소재. 가문 슬롯 IAP / 💀→💎 싱크 / 광고 "전설 +0.5% 24h" / **계보 체인 카드 공유**(판마다 다른 이야기라 공유 가치 성립). v1.1: 신규 특성, 야생 인자, 가문 리그.

### 반론 해소 기록
1. **교배 무의사결정(지배 시퀀스 반복)** → 계열 상성 도입: 동계열=Gen+1 사다리/이계열=변이 2배 도박으로 부모 조합이 결과를 바꾸고, 소환 결과가 판마다 사다리 계열을 정함. M3 시뮬에 "지배 시퀀스 유일하면 실패" 판정 추가(R4·M3).
2. **애착 대상 부재(매판 같은 T4)** → 융합이 최대 Gen 재료의 혈통 ID(이름·계열·변이 마크)를 승계, 정점 유닛에 계열 문장 오버레이 3변주, 가문 등록을 유닛 1장→계보 체인으로 교체(R4b·R8).
3. **M1 코어 수술 혼입·선행 의존** → M1a(쉘, 로직 무변경)/M1b(드래그 모드) 분할, 슬롯은 기존 startBreeding 임시 배선+겹치기 이때 제거, 홀드 확인은 M3까지 스텁 off·완료 판정 M3 이동(M1a·M1b).
4. **세이프존 무시 수직 예산** → 상단 바 y24~68/독 y536~624로 재산정, 트랙+스프라이트 반높이 16px 기준 겹침 0을 확인하고 config 상수 기반 순수 TS 테스트를 M1a 완료 판정에 포함(R1·M1a).

**마이너 반영**: ①가문 알→가문 시드(Gen 지름길 폐기) ②일반 변이 +10G·팡파레, 이계열 도박이 중간 낙차 공급 ③오라 겹수→형태 변화+금색 독점+스크린샷 지목 게이트 ④grep 범위 한정+허용 목록 ⑤시뮬 10만회·±3σ·피티 비활성 모드 ⑥M2 환불·M3 스키마 버전 테스트 ⑦일격 M3 플래그 off/M4 on ⑧⏸ 44×44 예산표 정식 포함(348px) ⑨드래그 오프셋·스냅·취소·바텀시트 판매 ⑩교배 슬로모+FTUE 1배속 ⑪확정 희귀=Gen+1(자식 Gen2)+후속 FTUE 스텝.
