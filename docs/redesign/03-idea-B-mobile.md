# 재설계안 B — 모바일 네이티브 전면 개편

## 1. 컨셉명 + 한 줄 피치

**「브리딩 디펜스: 리본(REBORN)」**
"탭 한 번에 소환, 겹치면 출산 — 7분 안에 신(神)을 낳는 한손 랜덤 디펜스. 매 라운드가 잭팟이다."

게임 시스템은 그대로, 제품을 다시 만든다. 목표: 스토어 스샷 5장 전부 '팔리는 장면'으로 교체 가능한 상태.

## 2. 코어 루프 변화 — 4박자 유지, 박자마다 '모바일 언어' 입히기

| 박자 | 현재 | 개편 후 |
|---|---|---|
| Plan | 브리핑 텍스트 팝업 | 라운드 핍 14개가 상단에 상시 노출 — "다음 보스까지 2라운드" 예측 가능 |
| Grind | 무음의 연속 스폰 | 소환마다 카드 낙차 연출 + 라운드 클리어 스탬프로 분당 3회 마이크로 보상 |
| Pop | T4 연출은 이미 최대치 | 유지(절대 불가침 1). 대신 W1 첫 세션에 'Pop의 예고편'을 심는다(§3-6) |
| Loop | 승리 팝업에 다음 목표 0 | 결과 카드에 별점 + "다음: W1-3에서 합성 해금" CTA 버튼 1개 고정 |

7분 고정 세션·30초 보스 박동·W1 해금 뼈대(불가침 2·3)는 수치 하나 안 건드린다.

## 3. 핵심 시스템 변경 6개

### 3-1. UI 킷 'JuicyButton' 일괄 리스킨 — 문제 #1
- **메커닉**: 공용 버튼 컴포넌트 1개 신설(`src/scenes/ui/JuicyButton.ts`). Phaser Graphics로 라운드 8px 사각 + 2px 금테 + 하단 3px 음영(입체감) + 상단 1px 하이라이트. 눌림 시 scale 0.94 / 80ms + 햅틱 10ms. primary(금)/secondary(올리브)/danger(적) 3변형. 기존 45개 텍스트 버튼을 전량 교체.
- **폰트**: monospace → WebFont 1종(예: 'Jua' 또는 'Gowun Batang' 로컬 임베드) + 숫자 전용 비트맵폰트 1벌(타이머·골드·대미지).
- **Graphics로 그림**: 버튼, 패널, 게이지, 핍, 재화 칩 배경. **NovelAI 생성**: 재화 아이콘 2종(젬·소울, 64px), 적 6종 스프라이트(👾🐝🐢👺👑💀 대체), T3 6종+T4 스프라이트(기존 잔여 계획과 동일).
- **재활용도: 상** — artnouveau.ts 금테 문법을 버튼으로 확장. 로직 무변경, 렌더 레이어만.

### 3-2. 한손 커맨드 독 — 문제 #2
- **메커닉**: 조작 버튼 전부를 하단 92px 독으로 이동. 중앙 **소환 버튼 96×64px**(가장 크게, 골드 비용 뱃지 부착), 좌측 한도+1(56×48), 우측 영혼상점(56×48). ⏸·📖·2×는 상단에서 제거하고 우상단 세로 스택 **48×48px** 원형 아이콘 3개(엄지 도달권 밖이어도 빈도 낮은 버튼만 상단 허용).
- **판정 규칙**: 전 버튼 최소 48×48px 히트영역(시각보다 커도 됨), `pointerdown`→`pointerup`+이동 8px 슬롭으로 전환(오발 방지). 판매존은 시각 표시와 판정 사각형(x≥290, y≥548)을 일치시키고 드래그 시작 시 독이 판매 모드(빨간 🗑️ 패널 120×92px)로 변신.
- **재활용도: 상** — HudRenderer 좌표·판정 수정만.

### 3-3. 라운드 언어 — 문제 #8 (기회 3 그대로 채택)
- **메커닉**: 30초 보스 박동을 "ROUND n"으로 명명. 7분=14라운드. 라운드 시작 배너(0.6s, 기존 배너 파이프라인 재사용) + 상단 타이머 옆 **핍 14개**(6×6px 원, 보스 라운드는 8px 해골 핍). 라운드 클리어 시 "ROUND CLEAR +5G" 스탬프(우상단 슬라이드인 0.8s). 스폰 스케줄·경제 수치 무변경, +5G만 신규(총 +70G/판, 시작 100G 대비 저위험).
- **GameOver 문구**: "웨이브 24 도달" 대신 "**라운드 9 도달** — 최고기록 라운드 11". 자랑 단위 확보.
- **재활용도: 상** — 타이머 기반 카운트 + 배너 재사용.

### 3-4. 소환 낙차 연출(뽑기 슬롯) — 문제 #7, #4
- **메커닉**: 소환 버튼 탭 → 독 위 카드 1장이 0.35s 뒤집힘 → 유닛 착지. 등급 연출 3단: **일반 T1** 흰 플래시 0.1 / **변이 출산(15%)** 보라 빔 + 셰이크 80ms + "MUTATION!" 배너 + 도감에 변이 마크 기록(기회 2, 수치 변경 0) / **잭팟 T2(기존 4%)** 금 빔 + 기존 잭팟 연출 승격. 교배 출산도 동일 카드 연출로 통일 — "출산=뽑기"라는 소재 약속을 연출로 이행.
- **재활용도: 상** — SummonSystem·확률 무변경, 연출 함수 1개 추가.

### 3-5. FTUE 재설계: 5스텝 행동형 튜토리얼 + 패배 학습 — 문제 #3
- **메커닉**: 19줄 텍스트 덮개 폐기. W1-1~5의 기존 기능 해금 뼈대(불가침 3) 위에 스텝형 오버레이: 검정 덮개에 **스포트라이트 구멍**(해당 버튼만 밝게) + 손가락 고스트 스프라이트(Graphics 원+궤적 트윈) + **강제 1회 수행 후 진행**. W1-1: ①소환 탭 ②드래그 배치 ③같은 카테고리 겹치기(❤ 3초) 3스텝, W1-2 이후 신기능당 1스텝. 발견 불가 인터랙션 8종을 전부 스텝으로 커버(더블탭 잠금은 W1-4).
- **패배 학습**: 적 한계를 4px 게이지 → 상단 중앙 **32px 카운트 링**(n/40, 32마리부터 빨간 맥동+햅틱)으로 승격. GameOver 카드 1행에 "**패배 원인: 적 40마리 초과**" + 미니 팁 1줄("판매로 골드를 만들어 소환하세요").
- **재활용도: 중** — TutorialPopup 교체, features 해금 로직은 무변경.

### 3-6. 첫 세션 Pop 예고 패키지 — 문제 #4
- **메커닉(시스템 무변경 3종 세트)**: ① **2배속 W1 무료 기본 제공**(메타 구매는 W2+용으로 문구 변경) — 이탈 최다 구간이 가장 느린 버전 문제 해소. ② W1-5 클리어 시 **T4 시네마틱 컷인**: NovelAI 풀스크린 일러스트 1장(Astral God) + "당신이 낳게 될 신" 텍스트 2.5s — 다음 세션의 Pop을 예고. ③ 승리 카드 CTA가 항상 다음 해금 기능 1개를 지목.
- **재활용도: 상** — 밸런스 무변경, 연출+문구.

## 7. 리스크와 완화책

1. **범위 폭주(리스킨 전면전)** — M1의 JuicyButton 1개가 45버튼을 커버하는 구조를 선행 강제. 화면 리스킨(M5)은 마지막, 이모지 제거는 재화→적→기타 순 단계적.
2. **연출 추가가 미해결 프리징 버그(보스 처치 시점)를 악화** — M3 착수 전 `#fatal-error` 추적 우선 해결을 게이트로. 신규 연출은 전부 트윈 풀 재사용.
3. **강제 튜토리얼이 재방문 유저를 막음** — 스텝 수행 기록을 저장, 클리어한 스테이지 재입장 시 스킵. features 해금 로직 자체는 무변경으로 충돌 차단.
4. **+5G/판(+70G)이 밸런스를 흔듦** — 유일한 수치 변경. 소환 상한가 30G 대비 2.3회분, W2-5 풀플레이 1회로 T4 도달 시점(4~5분 목표) 재검증 후 0G 폴백 스위치 유지.
5. **폰트/에셋 로딩으로 초기 로드 증가** — WebFont 1종 서브셋(한글 2,350자→사용 글리프만), NovelAI 신규분 WebP 변환, 타이틀 키비주얼은 지연 로드.
