> 2026-07-09 제정. 목표 재정의(사용자 지시): **모바일 게임이지만 Steam에 바로 출시 가능할 정도의 완성도**.
> 21번 채점표의 기준점(모바일 상위권 8점대)에 **Steam 기준선**을 추가하는 문서. 반복 디벨롭 1회차 — §5의 후속 회차 목록이 이 문서의 미완 부분.

## 1. Steam이 모바일과 다르게 요구하는 것

모바일 스토어는 스크린샷과 ASO로 팔리지만, Steam은 **첫 50개 리뷰**로 팔린다. 리뷰 문화가 강제하는 최저선:

| 축 | 모바일 기대치 (21번 기준) | Steam 최저선 | 어기면 |
|---|---|---|---|
| BM | F2P+보상형 광고+IAP (11번) | **프리미엄 단일 구매**, 광고 0 | "mobile port cash grab" 리뷰 폭탄 — 회복 불가 |
| 판형·입력 | 세로 터치 | 창/풀스크린, 마우스+키보드, (권장) 패드·Steam Deck | "obvious mobile port" 낙인 |
| 렌더 | 360×640 고정 | 해상도 독립 선명함 (업스케일 블러 불가) | 첫 스샷에서 환불 |
| 볼륨 | 세션 7분 반복 | **가격 1$ ≈ 1시간** 인식. $4.99면 실질 5h+ | "1시간이면 다 봄" 리뷰 |
| 사운드 | SFX만으로 견딤 | BGM 필수 (무음 = 즉사 리뷰) | G3와 동일 결론, 시급도만 상승 |
| 언어 | 한국어 우선 | **영어 필수** (EN 없으면 시장 ~95% 상실) | 위시리스트 자체가 안 쌓임 |
| 인프라 | 로컬 세이브 | Steam 클라우드 세이브 + 도전과제 15~30개 | 기대치 미달 감점 |
| 마케팅 | ASO (09번) | **데모 + Next Fest** = 1인 개발 최대 레버 | 노출 0 |

**총평**: 21번의 "패치 후 7.2 = 모바일 출시 가능선"은 Steam에선 아직 미달. 결정적 갭은 ①볼륨 ②판형/입력 ③BM 분기 ④영어. 나머지(BGM·클라우드·도전과제)는 기존 G3·G5의 시급도 승격으로 흡수된다 — **새 로드맵이 아니라 기존 로드맵의 재가중**이 대부분이라는 게 좋은 소식.

## 2. 판형 결정 — 세로 코어 유지 + 사이드 패널 (이번 회차 핵심 결정)

| 옵션 | 내용 | 판정 |
|---|---|---|
| A. 가로 재설계 | 필드·UI 전면 재배치 | 기각 — M1a~M4 레이아웃·세이프존·밸런스 전부 재작업, 1인 스코프 파산 (헌법 5조) |
| B. 세로 pillarbox 방치 | 좌우 검은 띠 | 기각 — "모바일 포트" 낙인의 전형 |
| **C. 세로 코어 + 좌우 정보 패널** | 360×640 필드 불변, 데스크톱에서만 좌우 패널 활성 | **채택** |

### C안 상세
- **게임 필드 360×640은 단 1px도 안 바뀐다** — 좌표·드래그·세이프존·밸런스·모바일 빌드 전부 무손상. 패널은 렌더 레이어 추가일 뿐.
- **좌 패널 = 계보 라이브 뷰**: 이번 판의 계보 체인(시조→교배→융합)이 판 중에 실시간으로 자라나는 트리. 모바일에선 바텀시트에 숨어 있던 P2(애착)를 상시 노출 — 세로 게임의 약점(좌우 여백)을 **코어 판타지 전시 공간**으로 뒤집는다.
- **우 패널 = 판 정보**: 라운드 타임라인(14칸)·적 구성 브리핑·일격/처치 통계. Plan 박자 강화.
- 포지셔닝 효과: "모바일 포트"가 아니라 **"데스크톱에서 혈통이 더 잘 보이는 낳는 게임"** — 스팀 스샷 1장(필드+계보 트리 동시 노출)이 곧 차별화 문구가 된다.
- 헌법 3문항: 박자=Plan(우)+Loop(좌) 강화 / 낳는 게임 정체성 **강화**(계보 상시 노출) / 7분 불변. **뺄 것**: Steam 빌드에서 보상형 광고 훅·💎 구매 UI 전체 제거(§3 S-D와 동일 결정으로 상쇄).
- 어셋: 패널 프레임은 아르누보 Graphics + NovelAI ≤2장(장식 보더) — 5조 2항 상한 내.

## 4. 이번 회차 확정 사항

1. **판형 = §2-C** (세로 코어 + 사이드 패널). 게임 로직·모바일 빌드 무손상이 절대 조건.
2. **BM은 플랫폼 분기**: 모바일 F2P(11번 유지) / Steam 프리미엄. 분기점은 BM·입력·패널 **3곳만** — 그 외 원 소스.
3. **S-F 키 구조만 M5 전 선결정** (실행은 별도). 나머지 S 시리즈는 M5 이후.
4. G3(BGM)·G5(클라우드) 시급도 승격 — Steam 최저선에 걸리므로.

> ⚠️ **헌법 충돌 고지 (5조 4항)**: "외부 SDK 도입은 Capacitor 패키징(BM2) 전까지 동결"은 모바일 기준 조항. Steamworks/Tauri 도입도 같은 취지로 **"패키징 마일스톤 이전 동결"로 확대 해석**해 준수한다 — 즉 S-E는 기획만 선행, 코드 도입은 패키징 M에서. 사용자 승인 시 이 해석을 헌법 각주로 승격.
