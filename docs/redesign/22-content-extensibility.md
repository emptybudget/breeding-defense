# 콘텐츠 확장성 분석 — 추가 유닛 슬롯·업데이트 지속가능성

> 2026-07-06. 질문: "추가 유닛이 들어올 자리와 당위성이 있나? 업데이트가 지속가능한 구조인가?"
> 답: **트리 안에 대형 슬롯 1개(제2의 신)가 구조적으로 예약돼 있고, 트리 밖에 무한 슬롯(변이종)이 있다. 단 T1~T3 추가는 수학적으로 봉인.**

## 1. 합성 트리 포화도 (수학)

| 층 | 슬롯 수 | 현재 | 판정 |
|---|---|---|---|
| T2 (이종 카테고리 조합) | 3쌍×2×2 = **12** | 12 | **포화** — 추가 불가 |
| T3 (T2 2개 고정 레시피) | 12÷2 = **6** | 6 | **포화** |
| T4 (T3 3개 레시피) | 6÷3 = **2** | **1** | ⭐ **1자리 공석** |
| T1 추가 시 | 계열당 +1이면 T2가 27종으로 폭발 (신규 15종 제작) | — | **봉인** — 우아함이 곧 한계 |

**결정적 발견: 현 T4(Astral_God)는 Griffin+Thunder_Hawk+Cyborg_Wizard만 소비한다. Dino_Mecha·Berserk_Shaman·Chaos_Artillery 3종은 어떤 상위 레시피에도 안 쓰인다** — 처음부터 제2 T4를 위해 비워둔 것처럼 정확히 3종이 남는다.

## 2. 확장 슬롯 목록 (당위성 순)

### S1 ⭐ 제2의 신 — 「Ruin_God (종말수)」 (대형 업데이트 1회분, v1.2급)

- **레시피**: Dino_Mecha + Berserk_Shaman + Chaos_Artillery (남은 3종 정확히 소비 — 트리 완결).
- **당위성 3중**: ①구조(빈 슬롯) ②서사(창조신 Astral 🌟 천상·질서 ↔ 파괴신 Ruin 🌋 지상·광란 — "신을 낳는 게임"이 **"어느 신을 낳을 것인가"** 로 진화) ③기획(21번 채점의 'T4 단일 종착지 = Loop 붕괴' 잔여 문제의 최종 해결 — 엔드게임 빌드가 2갈래).
- **차별화 컨셉**: Astral = 8타겟 체인·보장 크리(현행 유지) / Ruin = **소수 대상 초폭딜 + 주기적 광역 분노(주변 아군 공속 버프)** — "쓸어담기 vs 뚫어버리기". 보스전은 Ruin이, 물량전은 Astral이 우위 → 스테이지 브리핑(Plan)과 맞물림.
- 필요 어셋: 유닛 1(idle+attack 2장) + 컷인 공유 + 알은 기존 재사용. 밸런스: 12번 방법론 시뮬 필수.
- 스토어 각도: "두 번째 신 강림" — 업데이트 배너 한 장으로 복귀 유저 소환.

### S2 ♾ 히든 변이종 라인 (트리 밖 무한 슬롯, 시즌당 1~2종)

- **전설 변이 시 낮은 확률(예: 20%)로 기존 종 대신 '각성종' 출산** — 예: 알비노 늑대(Bio_Wolf 변이), 황금 다람쥐, 유리 안드로이드.
- 트리 밖이므로 **조합 폭발 없음** — 레시피·합성에 안 끼고, 스탯은 원종+고정 특성 1(밸런스 부담 최소), 가치는 **도감·계보·과시**.
- 도감 "변이종" 탭 신설 → 수집 축이 25종에서 무한 확장. 뽑기 심리(전설 변이)에 콘텐츠가 직결되는 구조라 BM(부화당 스킨)과 시너지.
- 필요 어셋: 종당 1장 (기존 시드+색·토큰 변주라 제작비 최저).

## 3. 지속가능성 판정 — 시즌 템플릿

**시즌(4~6주) 표준 구성** = S2 변이종 1 + S3 특성 2 + S6 스킨 4~6(패스 포함) + S5 주간 시드(자동) + 격시즌 S4 적 1종.
→ 시즌당 제작비: **NovelAI ~8장 + 코드 소~중** — 1인 개발이 부업으로도 유지 가능한 볼륨. 반기마다 대형 1회(S1 제2 신 → 월드 4 → 가문 리그).

| 질문 | 냉정한 답 |
|---|---|
| 콘텐츠가 계속 나올 구조인가 | **예** — 트리는 잠갔지만(품질 방어) 트리 밖 축 6개가 열려 있고, 시즌 템플릿의 병목(아트)이 AI 파이프라인이라 소진 안 됨 |
| 신규 유입이 계속되나 | **조건부** — 마케팅 0원 구조라 오가닉 의존: ASO 저경쟁 키워드("교배/breeding")+공유 카드+업데이트 피처링이 전부. 정직하게 말하면 **바이럴 한 방 없이는 완만** — S1(두 번째 신) 같은 "뉴스가 되는 업데이트"를 반기 리듬으로 배치하는 이유 |
| 돈이 되는 구조인가 | **예, 소규모로** — 스킨(한계비용 0)+패스+광고가 시즌 리듬에 결합. 21번 추정대로 초기엔 학습용 매출, DAU 1만부터 유의미 |

## 4. 하지 않는 것 (봉인 목록)

- **T1/T2/T3 층 추가** — 조합 폭발(수학 §1). 25+1종의 우아함이 이 게임의 품질이다.
- 제3의 신 — T3 슬롯이 없다. 신은 영원히 둘 (이원 구도가 서사적으로도 완성형).
- 신규 계열(제4 문) — T2 12종 신규 제작 = 사실상 리메이크. 기각.

**한 줄 결론**: 유닛 확장은 "옆으로"(변이종·스킨) 무한하고, "위로"는 딱 한 번(제2의 신) 남았다 — 그 한 번을 가장 큰 뉴스로 아껴 써라.
