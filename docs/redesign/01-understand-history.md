## 1. 확정된 디자인 결정

**코어 판타지:** "스테이지를 보고 빌드를 짜고, 고생해서 고티어를 완성하면, 한 방에 쓸어버리는 쾌감" — 4박자 사이클 **Plan(적 보고 빌드 결정) → Grind(운+합성+자원 압박) → Pop(고티어 완성 싹쓸이) → Loop(다음 스테이지)**. 참고: 히어로즈 랜덤 디펜스(메인)/운빨존많겜/Vampire Survivors. 한 판 7분(출퇴근 사이클). PvE 메인, 엔드콘텐츠=점수 경쟁(추후).

**시스템 결정 표:**
| 시스템 | 결정 |
|---|---|
| 골드 공급 | 적 처치 + 매초 +2G 자동회복 |
| 종족 선택 소환 | **철회 — 랜덤 묘미 유지** |
| 시너지 | 메뉴 영구 업그레이드로 해금 |
| 메타프로그레션 | 영구 강화 4종 + 💎 보석 화폐 |
| 스테이지 | 월드 3×5=15. W1=튜토리얼 전용. 5분 강화는 W2·W3만 |
| 아트 | NovelAI 확정, 이모지 폴백 단계적 제거 |
| 고티어 선택권 | 부분 — 레시피 팝업으로 조합식 공개 |

**월드 설계 (확정):**
- **W1 튜토리얼(2~4분):** 스테이지별 UI 잠금 해제 — 소환만→교배→합성·판매→잠금·영혼상점→레시피북·메타 전부. 숨긴 버튼은 invisible(disabled 아님). 5분 강화 미적용.
- **W2 본게임(7분×5):** NORMAL/FAST 중심→TANK 점증, W2-5 ELITE+보스HP×1.5.
- **W3 하드(7분×5):** TANK 고밀도, W3-4 ELITE 45s→30s, W3-5 보스HP×1.5+5분강화×2.0.
- 잠금: 출시 시 W1 전체 클리어→W2 해금(개발 중 `DEV_UNLOCK_ALL_WORLDS=true`).
- 5분 강화: 300초에 적 HP·Speed ×1.5 1회, W2·W3만.

**아트 결정(design-prompts.md):** 아르누보-Chibi 하이브리드(B안) 확정, 다크판타지+골드 액센트, NovelAI v4.5 메인+Midjourney 보조. 무하 액센트 T1 절제→T4 만개(Pop 서사 시각화). 3/4 좌향+자연 idle 포즈(정면 T포즈 폐기, 좌우 반전으로 방향 표현). **공격모션은 추가 생성 없이 Phaser tween+이펙트로**(T4만 attack 2프레임 예외). 이펙트 4종은 검정배경+가산합성 트릭으로 NovelAI 생성 예정.

- **메타/모바일:** 월드15스테이지+StageSelect, 영구강화 4종+2배속+잭팟, 스테이지 최고기록, 광고부활(시뮬), 햅틱, 안전영역, 백그라운드 정지, DPS 미터 Top3, Web Audio BGM/SFX.

## 5. 플레이테스트 실제 유저 피드백 (2026-06-16, W2-5 풀플레이)

1. **4티어 완성 시점 4~5분** — 목표(4:00~5:00) 충족, U7 조정 불필요.
2. **"보스 페이즈 구분이 체감 안 됨"** — Phase C 처치시간 측정 불가의 원인. → GD1 컷인으로 대응 완료.
3. **"4티어 1개로 끝까지 살짝 부족한 느낌 = 낫배드"** — 의도된 긴장감으로 판정, 난이도 조정 보류.
4. **강화 점 사용 패턴 미보고**, 7분 도달률 별도 측정 안 함(현행 유지 결정).
5. 종합: "난이도 나쁘지 않음" → G4 투입 허가, G5 보류.
6. (버그) **인게임 프리징 — 보스 처치 시점 의심**, 원인 추적 중(`#fatal-error` 오버레이 삽입, 순수 데이터 레이어는 무죄 확인).
