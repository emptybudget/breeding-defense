## A안 — 「명가: Bloodline Defense」 상세

### 재미 8.0
- 치명 문제 5(교배=느린 소환)를 정면 타격. 게임 제목이 breeding-defense인데 교배가 코어가 아닌 모순을 해소하는 유일한 정공법.
- Pop이 판당 1회→3~5회(변이 3등급 잭팟 + Gen5 완성). 문제 4·7의 "도박 낙차 결핍"을 수치 변경 최소로 해결.
- T1 6종×특성 12종=72 표현형 → 빌드 깊이 폭발. 이름 자동생성+혈통서로 유닛이 소모품→개체가 됨(애착 축 신설).
- 감점 요인: 초당 전투 감각 자체는 무변경. 시스템 3중 추가로 FTUE 과부하 리스크(스스로 인지·완화책 있음). UI 치명 문제 1~3은 둥지 패널 외 미해결.

### 개발난도 6.0
- 강점: 5개 시스템 중 S2(특성)·S3(변이)는 기존 T2 기믹 12종 코드+주스 자산 재조립 — 신규 로직 거의 0. M1이 순수 TS 유닛 테스트(1만회 시뮬 오차 ±1%p)로 완결 → **하위 AI 모델이 브라우저 없이 자가 검증 가능한 이상적 마일스톤 형태**.
- 약점: Gen 계승이 교배·합성·판매·도감·저장 전 계통에 스며듦 → 회귀 표면 넓음. M5 밸런스 패스(Gen 커브×특성 상속률)는 사용자 풀플레이 의존이라 루프가 김. 둥지 UI+예상 혈통 카드는 신규 UI 2장.
- 아트 부담: 알 스프라이트 3장뿐(초상은 기존 크롭). 죽는 자산 0.

### 지속가능성 8.0
- 치명 문제 6(실콘텐츠 14분) 직격: 최종 목표가 "T4 1종"→"Gen4+ T4 + 특성 조합 + 가문 도감"으로 다층화. 같은 W2-5를 돌아도 "이번 판은 지난 판의 자식" — 판이 서로 연결됨.
- 가문 계승 = "오늘 켤 이유"(문제 7)의 뼈대. 영혼 이월+2차 트리 3종이 미결정 메타 항목을 확정하며 장기 파워 커브 개통.
- 업데이트 확장성 최상: 신규 특성 1종 추가 = 콘텐츠 패치 1회. 시즌 한정 변이, 가문 리그(점수 경쟁 엔드콘텐츠 방향과 합치)로 자연 확장.
- 감점: 스테이지 15개 자체는 그대로라 "새 판"의 공급은 여전히 유한. Gen 인플레가 긴장감("T4 살짝 부족" = 의도된 판정)을 깰 밸런스 리스크.

### 비즈니스 7.0
- 수익 표면: 가문 슬롯 확장(IAP), 가문 알 Gen 상한/상속률 부스트(💀→💎 싱크), "전설 변이 확률 +0.5% 24h"(광고 시청), 혈통 카드 공유(GD6과 통합, 바이럴).
- "출산에서 최강 유닛이 나오는 유일한 랜덤 디펜스" — ASO 차별화 문구로 독점 포지션(기회 1).
- 감점: 스토어 스크린샷 문제(문제 1: 팔리는 장면 0장)를 A 단독으로는 못 고침 — 혈통 시스템이 아무리 깊어도 메모장 UI 위에서는 스샷이 안 팔림. B 접목 필수인 이유.

## B안 — 「브리딩 디펜스: 리본」 상세

### 재미 6.5
- 기존 재미의 "전달"을 고침: 첫 세션 2배속 무료+T4 컷인 예고(문제 4), 라운드 언어(문제 8), 소환 카드 낙차(문제 7 일부), FTUE 5스텝(문제 3). 전부 정확한 처방.
- 그러나 새 결정·새 동사·새 낙차원은 0. Pop 이후 관전 모드, 교배=느린 소환, 같은 산 같은 길 — 심장부 3개(문제 5·6·8 후반)가 그대로. "잘 포장된 14분"이 됨.

### 개발난도 9.0
- 3안 중 압도적 최저 난도. 로직 변경은 +5G/판 하나뿐, 나머지 전부 렌더 레이어. JuicyButton 1개→45버튼 구조가 스코프 폭주를 원천 차단.
- 마일스톤 완료 판정이 기계 검증형(grep 0건, 히트영역 상수 테스트, 이모지 60→20) — 하위 AI 모델에게 가장 안전한 작업 형태.
- 유일한 마찰: UI 품질의 최종 판정은 사용자 IDX 육안 확인 의존(아키텍처상 불가피). NovelAI 신규 17장은 확립된 파이프라인이라 한계비용 낮음. 만점이 아닌 이유: M5 전면 리스킨 자체 물량 + 프리징 버그 선결 게이트.

### 지속가능성 5.0
- 문제 6 무대응 — 실콘텐츠 14분이 예쁜 14분이 될 뿐. 판을 넘는 진행 0, 메타 이월 0, "오늘 켤 이유" 신설 0.
- 라운드 최고기록("라운드 9 도달 — 최고기록 11")이 유일한 리텐션 신규 훅. D1은 오르겠지만 D7을 지탱할 구조가 없음.
- 단, 이후 어떤 콘텐츠를 얹어도 팔리는 그릇이 된다는 점에서 "지속가능성의 전제조건"이긴 함.

### 비즈니스 8.0
- 스토어 스샷 5장 전부 교체 가능 = 3안 중 유일하게 **전환율(설치)** 문제를 직접 해결. 키비주얼+결과 카드+라운드 언어는 스토어 영상 소재로 즉시 사용 가능.
- 광고/IAP 표면 신설은 거의 없음(오히려 W1 2배속 무료화로 💎3 상품 하나 후퇴 — 올바른 결정이지만 수익 표면은 감소).
- 요약: 퍼널 상단(설치·D0)은 최강, 퍼널 하단(과금·D7)은 무대응.

## C안 — 「사냥꾼의 방주」 상세

### 재미 8.5
- 3안 중 순간 재미 최고점. "죽이지 마라, 낚아채라"는 장르의 유일 동사를 뒤집는 진짜 와일드카드 — 매 라운드 "비상 밸브 vs 희귀 인자 온존" 결정이 발생, 문제 8(Pop 이후 동사 부재)을 가장 확실히 해결.
- 각성 출산(변이×인자 곱연산)의 잭팟 설계 우수, W1-3 "첫 사냥"은 첫 세션 Pop(문제 4)의 3안 중 최선 답안.
- 감점: 방주 영구 사망은 모바일 F2P 손실 회피와 정면 충돌(스스로 인지). "교배" 정체성이 "사냥"으로 반쯤 이동 — 소재 약속(문제 5)의 이행이 A보다 간접적.

### 개발난도 5.5
- 강점: 재활용 맵 치밀(적 타입·ELITE·보스 페이즈·T2 기믹 전용), 폐기 자산 0, M1~M2 수직 슬라이스 성립.
- 결정적 약점: **포획 1.2초 유예창 vs T4 400 DPS 충돌은 실시간 감각 튜닝 문제** — 순수 TS 시뮬로 검증 불가, 사용자 육안 플레이 루프에 전적으로 의존. 하위 AI 모델+헤드리스 금지 환경에서 가장 비싼 종류의 작업. 인자 5종 밸런스(보스 인자 광역 폭발)도 동일.
- 신규 표면: 그물 버튼·표식·인자 칩 5슬롯·방주 화면 1장·묘비 — UI 신규량이 A보다 많음.

### 지속가능성 7.5
- 방주 계승이 문제 6을 붕괴시키는 설계("무엇을 걸까"로 매 판 개인화)는 A의 가문과 동급. 인자 도감·묘비 서사·💀 정산(지는 판에도 수확)은 리텐션 훅으로 우수.
- 감점: 영구 사망이 이탈 트리거가 될 수 있음(위로금 💀30으로 완화되나 검증 필요). 확장 축이 "신규 인자 추가"인데 인자는 적 타입에 종속 — 적 3종+ELITE+보스뿐이라 특성 12종을 가진 A보다 확장 재료가 얇음.

### 비즈니스 7.0
- "방주 유닛 사망 시 광고 보고 1회 소생"은 3안 통틀어 가장 자연스러운 광고 표면. 방주 칸 확장 IAP, 그물 +1발 광고도 직관적.
- 포획 순간은 스토어 영상 소재로 차별성 있음("적을 낚아채는 디펜스").
- 감점: 손실 회피 기반 수익화는 다크패턴 인상 리스크(리뷰 평점 하방). 스샷 문제는 A와 동일하게 미해결.

## Combo 전략 — "A의 심장, B의 몸, C의 예비 장기"

3안은 상호배타가 아니다. 실행 순서로 통합한다:

1. **Phase 0 = B의 쉘 선행 (B-M1~M2 + 3-3/3-5/3-6)**: JuicyButton 45버튼 일괄 + 커맨드 독 + 라운드 언어 + FTUE 스포트라이트 스텝 + W1 2배속 무료 + T4 컷인. A의 둥지·잭팟 연출·혈통 카드가 팔리는 UI 위에 올라가야 스토어 소구가 성립하고, 렌더 레이어 선행은 하위 AI 모델의 워밍업으로도 최적. (B-M5 전면 리스킨은 후순위로 미룸)
2. **Phase 1~2 = A 골격 (A-M1~M3)**: 혈통 데이터층(순수 TS 시뮬 검증) → 둥지 UI+3등급 잭팟 → 혈통 가시화(이름표·GameOver 사인·혈통서). A-M1+M2만으로 수직 슬라이스.
3. **Phase 3 = A 메타 (A-M4~M5)**: 가문 계승 + 영혼 이월 + 2차 트리 + 밸런스 패스. C의 방주 대신 A의 가문을 채택하는 이유: 영구 사망 없이 같은 문제 6을 풀며 손실 회피 리스크 0.
4. **v1.1 업데이트 훅 = C 이식**: "라운드 인자 예보" + ELITE/보스 한정 희귀 "야생 인자"를 교배 재료로 1~2종만 도입(그물 대신 처치 드랍으로 단순화 — 1.2초 유예창 튜닝 문제 제거). C의 포획 동사 전체는 지표(D7·과금) 확인 후의 확장 카드로 보존.
5. **기각**: C의 영구 사망, B-M5 전면 리스킨의 일괄 투입(단계적 분할), A 가문 알 Gen2 초과 상한.
