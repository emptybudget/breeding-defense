# 재설계안 A — 교배를 게임의 얼굴로

## 1. 컨셉명 + 한 줄 피치

**「명가(名家): Bloodline Defense」**
"뽑는 게임이 아니라 낳는 게임 — 당신이 직접 교배로 길러낸 5세대 혈통이 보스를 쓸어버리는 유일한 랜덤 디펜스."

## 2. 코어 루프 변화 — 4박자의 재배선

Plan→Grind→Pop→Loop 뼈대는 유지하되, 각 박자에 "혈통"이라는 세로축을 꽂는다.

| 박자 | 현재 | 개편 후 |
|---|---|---|
| Plan | 적 타입 보고 카테고리 결정 | + "이번 판에 어느 가문(특성)을 기를지" 결정. 시작 시 가문 시조 알 1개 선택 투입 |
| Grind | 소환+합성 반복 | 합성(질서·확정 레시피)과 **교배(카오스·혈통 RNG)** 의 이중 축. 교배는 세대·특성·변이를 굴리는 능동 도박 |
| Pop | T4 완성 1회 | + **변이 잭팟**(즉발 낙차)과 **Gen5 혈통 완성**(누적 낙차) — Pop이 판당 1회에서 3~5회로 |
| Loop | 같은 산 같은 길 | 판 종료 시 최고 혈통이 가문으로 영구 등록 → 다음 판의 시작 자원이 됨. "이번 판은 지난 판의 자식" |

## 3. 핵심 시스템 변경 5개

### S1. 혈통 세대(Gen) 시스템 — 문제 5·6

- 모든 유닛에 `gen: 0~5` 필드. 소환 유닛=Gen0. 교배 자식=`max(부모 Gen)+1`.
- Gen당 공격력·공속 **+8%** (Gen5 상한 +40%). Gen은 소환으로 절대 못 얻고 교배로만 상승 → "교배=느린 소환" 낙인 제거.
- 합성 시 재료 유닛들의 **Gen 평균(내림)을 결과물이 계승** → 고세대 T1을 기르면 T4까지 이득이 전파. 최종 목표가 "T4"에서 "**Gen4+ T4**"로 확장(문제 6의 '같은 산' 해소).
- 자식 이름 자동 생성: 부모 이름 앞뒤 음절 조합(예: 슬라임 "포포"×"미미"→"포미"). 유닛 헤드 위 10px 이름표(Gen2+만 표시, 화면 오염 방지).
- **재활용도: 중** — UnitData 확장 + 교배/합성 로직 수정. 렌더는 이름표 1종 추가.

### S2. 특성 1슬롯 상속 — 문제 5·7(빌드 깊이)

- 기존 T2 기믹 12종(스플래시·체인·넉백·지뢰·오라 등)을 `trait` 데이터로 승격. T2+는 고유 특성 기본 보유, T1은 특성 슬롯 1개(기본 빈칸).
- 교배 상속 규칙: 한쪽만 특성 보유→**50%** 상속 / 양쪽 보유→각 **40%** + **20%** 로 제3의 무작위 특성(잡종 강세).
- 결과: "스플래시 달린 T1 궁수" 같은 조합 폭발 — T1 6종×특성 12종=72가지 표현형. 합성 시 재료 중 1개 특성을 확률 60%로 계승해 "특성 있는 T3/T4" 빌드가 성립.
- **재활용도: 상** — 기믹 로직 12종이 이미 코드로 존재, 유닛-특성 바인딩만 데이터화(U4 가시성 패스와 동시 해결).

### S3. 변이 3등급 + 잭팟 연출 — 문제 7(도박 낙차)·1

- 기존 변이 15%를 3등급으로 분해(총확률 동일): **일반 12%**(타종 변이, 현행) / **희귀 2.5%**(Gen+2 점프) / **전설 0.5%**(특성 2슬롯 + 금빛 이름).
- 연출(기존 주스 자산 조립): 부화 직전 알이 0.4s 프리즈 → 등급색 플래시(백/청/금) → 셰이크 200/350/500ms + 등급 배너("변이!"/"희귀 변이!!"/"전설 탄생!!!") + 햅틱 3/4/5단. GD1 컷인 파이프라인 그대로 재사용.
- 전설 변이는 도감·판 결과 카드에 영구 기록.
- **재활용도: 상** — 수치 재배분 + 기존 연출 시스템 조합.

### S4. 가문 계승(메타 이월) — 문제 6·7("오늘 켤 이유")

- 판 종료 시(승패 무관) **최고 Gen 유닛 1마리를 "가문"으로 도감에 등록**(종·Gen·특성·이름·탄생 스테이지 기록).
- 다음 판 시작 시 💀영혼 이월분으로 **가문 알 1개 구매**(가격 예: Gen1=💀3, Gen2=💀8, 상한 Gen2 — 시작 스노우볼 방지). 부화하면 해당 혈통의 Gen0+특성 보유 유닛 → "지난 판의 유산으로 이번 판을 연다".
- 영혼상점에 "가문 강화" 2차 트리 3종(가문 알 Gen 상한 +1 / 특성 상속률 +5% / 희귀 변이 +0.5%) — 미결정이던 메타 2차 트리를 혈통 테마로 확정.
- **재활용도: 중** — 도감(G3)·영혼상점·최고기록 저장 구조 확장.

### S5. 둥지 UI — 교배의 무대화 — 문제 3·2·5

- "같은 카테고리 2마리 겹치기"(발견 불가 인터랙션)를 폐기하고, 하단 엄지존에 상시 **둥지 패널**(높이 88px, 슬롯 2개 각 56×56px) 신설. 유닛을 둥지로 드래그 → 2슬롯 차면 **예상 혈통 카드** 자동 표시(자식 Gen, 특성 상속 확률 %, 변이 확률) → "교배" 버튼(64×48px, `pointerup` 판정) 탭 → 3초 알 게이지 → 부화.
- 확률을 사전에 보여주는 건 결과 미리보기가 아니라 **기대치 공시**이므로 기각된 '합성 미리보기 고스트'와 무관(합성엔 미적용).
- W1-2에서 둥지가 금빛 펄스+손가락 아이콘으로 등장 — 튜토리얼 텍스트 없이 발견 가능.
- **재활용도: 중** — 교배 판정 로직 재사용, UI 패널 신규(artnouveau.ts 금테 패널 재활용).

## 6. 마일스톤 초안

1. **M1 혈통 데이터층** — UnitData에 gen/trait/이름, 교배·합성 계승 규칙, 변이 3등급 판정. 완료 판정: 순수 TS 유닛 테스트(상속 확률·Gen 전파·등급 분포 1만회 시뮬 오차 ±1%p) 통과 + `npm run build` 성공.
2. **M2 둥지 UI + 부화·잭팟 연출** — 둥지 패널, 예상 혈통 카드, 3등급 연출. 완료 판정: 빌드 통과 + 사용자 IDX 플레이로 "설명 없이 교배 발견 가능" 확인.
3. **M3 혈통 가시화** — 이름표, GameOver 사인+혈통 카드, 혈통서 탭. 완료 판정: 사용자가 패배 원인을 팝업만 보고 말할 수 있음.
4. **M4 가문 계승 메타** — 가문 등록/출전, 영혼 이월, 2차 트리 3종. 완료 판정: 2판 연속 플레이에서 1판 혈통이 2판 시작에 등장.
5. **M5 밸런스 패스** — Gen 커브·특성 상속률 튜닝. 완료 판정: W2-5 풀플레이에서 T4 완성 4~5분 유지 + Gen3+ 달성.
