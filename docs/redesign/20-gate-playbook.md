## 공통 원칙 재확인

- 게이트 실패의 절반은 **버그**(배선·플래그·상수 불일치)다 — 밸런스 노브를 돌리기 전에 완료 판정 테스트부터 재실행.
- 노브를 돌렸으면 반드시 같은 조건으로 재측정. "느낌상 나아짐"은 측정이 아니다.
- 이 표에 없는 증상을 만나면: 증상·재현 조건을 PROGRESS에 기록 → 헌법 부칙 체크리스트로 심사 → 필요 시 이 문서에 행 추가.
