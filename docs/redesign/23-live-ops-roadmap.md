# 라이브 대형 업데이트 로드맵 — 유닛 너머의 축 + 이탈률 설계

> 2026-07-06. 22번의 결론("위로는 한 번뿐")은 **유닛 트리에 한정된 얘기**다. 이 문서는 그 위 층위: 트리를 건드리지 않는 대형 시스템 축 6개와, 각 축이 어느 이탈 구간을 막는지. 헌법 제1조(4박자·낳는 게임·7분) 전 항목 통과분만 수록.

## 0. 재프레임 — 대형 업데이트의 정의

유닛 추가는 "뉴스"지 "축"이 아니다 (소비되면 끝). 대형 축 = **기존 콘텐츠 전체의 가치를 재계산하게 만드는 시스템**. 이 게임은 혈통·가문·계보라는 서사 자산이 있어서, 축을 세울 자리가 유닛 트리 밖에 넓다.

## 1. 대형 축 L1~L6

### L1 유파(流派) — 특성 세트 시너지 (분기 1 권장)
- **내용**: 특성 2~3개 조합에 세트 효과 부여 — 예: 「일격유파」(근접 기믹 2특성 = 혈통 일격 주기 −1) 「포격유파」(스플래시+지뢰 = 폭발 반경 +30%). 유파 성립 시 정점 유닛 문장에 유파 인장 추가.
- **당위**: PROGRESS 미결정 항목 "시너지 카탈로그 5~10개"의 정식 해소. **유닛 0종 추가로 빌드 경우의 수 폭증** — R5 특성 구조가 이미 슬롯. 신규 어셋 0~2장.
- **이탈 방지**: 숙련 유저의 최적화 놀이(이론작) — D30+ 코어층.

### L2 가문 전당(殿堂) — 애착의 장기화 (분기 2~3)
- **내용**: ①가문 레벨(계보 등록 누적 → 가훈 패시브 1슬롯 해금: "상속률 +3%" 등 소폭) ②시조 전당 — 가문 슬롯이 차면 오래된 가문을 삭제가 아니라 **은퇴** — 초상+기록이 전당에 영구 보존 ③가문 연대기: 판마다 한 줄 자동 기록("3월 7일, 벼락송곳니 4세가 종말수를 무찌르다").
- **당위**: 삭제→은퇴 전환은 **매몰 애착을 지우는 대신 쌓는** 구조 변경. 수집(도감)과 서사(연대기)의 결합.
- **이탈 방지**: "내 가문 역사"라는 개인 자산 — 접는 순간 버려지는 게 생김. D90+ 장기.

### L3 신들의 대립 — Ruin_God을 1회성에서 영구 축으로 (분기 2, 22-S1과 결합 출시)
- **내용**: 제2 신 출시와 **동시에** 진영 시스템: 판 시작 전 신앙 선택(Astral=질서: 사다리 변이 +2%p / Ruin=광란: 이계열 변이 +4%p) → 주간 진영 점수 합산 → 승리 진영 다음 주 소폭 버프+한정 칭호. 진영 한정 변이종 각 1종.
- **당위**: 유닛 1종 드랍(소모성 뉴스)을 **매주 갱신되는 소속감 콘텐츠**로 전환 — 같은 제작비로 축을 하나 얻는다. G1 리더보드 인프라 재사용.
- **이탈 방지**: 주간 리듬 + 소속감(가벼운 소셜) — D7~D30.

### L4 침공(侵攻) — 역설계 비동기 대전 (분기 3~4, 색다름의 정점)
- **내용**: 내가 **적 웨이브를 편성**해(포인트 예산 내 적 타입·타이밍 배치) 시드로 발행 → 다른 유저의 가문이 도전 → 방어 성공률로 내 웨이브에 악명 점수. "디펜스 게임에서 공격을 설계한다"는 역발상.
- **당위**: G1 주간 시드의 상위 호환 — 콘텐츠를 **유저가 생산**(1인 개발의 궁극 지렛대). 서버는 시드 문자열+통계뿐이라 저비용.
- **이탈 방지**: UGC 루프 — 내 웨이브의 성적 확인이 "오늘 켤 이유". 리스크: 밸런스 어뷰징 — 예산제+신고로 방어, 반드시 별도 모드로 격리(헌법 7분 원칙 보호).

### L5 월드 4 「몰락한 영지」 (분기 4 / 연 1회 페이스)
- **내용**: 신규 스테이지 5 + G2 이후 적 2종 + 환경 기믹 1(예: 안개 — 사거리 −20% 구역) + 유물 알(BM) 세계관 연결 — "몰락한 가문들의 땅에서 그들의 알을 회수한다".
- **당위**: 정통 볼륨 확장. BM 부화당의 서사적 근거를 겸함.
- **이탈 방지**: 클리어형 유저의 신규 목표 — 복귀 트리거.

### L6 시즌 이벤트 프레임 (1회 구축, 무한 재사용)
- **내용**: 「계절 대제전」 틀 — 한정 변이종 1 + 테마 스킨 셋 + 특별 룰 주간 시드(예: "모든 교배 이계열 취급") + 이벤트 패스 트랙. 틀을 한 번 만들면 이후 시즌은 **데이터+아트만 교체**.
- **이탈 방지**: 한정성(코스메틱 한정만 — 헌법 제4조·11번 원칙 준수) — 전 구간 복귀 트리거.

## 2. 이탈 구간별 방어 매핑

| 이탈 구간 | 주 원인 | 막는 것 |
|---|---|---|
| D1 | 재미 미전달 | 명가 패치 본체 (FTUE·첫 세션 Pop) |
| D7 | 할 게 없음 | G4 일일 + G1 주간 시드 + **L3 진영 주간** |
| D30 | 최적화 끝 | **L1 유파** + G2 적 카운터 + 리더보드 등반 |
| D90+ | 애착 소진 | **L2 전당·연대기** + L5 월드 + L6 시즌 한정 |
| 복귀 | 계기 없음 | **복귀 설계**: 접속 없던 14일+ 유저에게 "〈가문명〉이 기다립니다" 푸시/배너 + 복귀 주 유물 알 3개 + 시즌 첫 주 캐치업 점수 보정. 대형 축 출시 = 복귀 캠페인과 항상 동시 집행 |

## 3. 연간 캘린더 (출시 후 12개월 예시)

| 시점 | 내용 | 성격 |
|---|---|---|
| 출시+2주 | G4 일일 도전 + 소킹 정리 | 긴급 리텐션 |
| +1개월 | G2 적 3종 + G3 BGM | 완성도 |
| +2개월 | G1 주간 시드·리더보드 + BM1 부화당 | 엔드게임+수익 |
| **분기 1** | **L1 유파** (+ 시즌 1 개막, L6 틀 구축) | 대형 |
| **분기 2** | **L3 신들의 대립 (Ruin_God 강림)** | 최대 뉴스 |
| **분기 3** | **L2 가문 전당** 또는 **L4 침공** (지표 보고 택1) | 대형 |
| **분기 4** | **L5 월드 4** + 연말 대제전 | 볼륨 |

> 분기마다 대형 1 + 시즌 1 — 22번 시즌 템플릿(변이종·특성·스킨)이 대형 사이를 메운다. **12개월간 "다음에 뭐 나오지"가 비는 달이 없다.**

## 4. 답변 요약 (질문에 대한 직답)

- **"큰 업데이트가 4티어뿐인가?"** — 아니다. 유닛 프레임에서만 그렇고, 시스템 축(유파·전당·진영·침공·월드·시즌틀) 6개가 트리 무관하게 열려 있다. 심지어 제2 신도 L3로 포장하면 1회성 뉴스가 아니라 영구 축이 된다.
- **"지속가능한가?"** — 분기 대형 1 + 시즌 소형의 2단 리듬으로 12개월 계획이 이미 서 있고, 병목(아트)은 AI 파이프라인이라 마르지 않는다.
- **"기존 고객 이탈은?"** — 구간별(D1/D7/D30/D90/복귀) 방어 장치를 §2에 매핑 — 특히 L2(가문 전당)가 이 게임만 가능한 이탈 방지 장치다: **버리고 떠나기 아까운 건 스펙이 아니라 역사다.**
