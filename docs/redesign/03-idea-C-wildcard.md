# 방향 C — 와일드카드: 「사냥꾼의 방주 (Hunter's Ark)」

## 1. 컨셉명 + 한 줄 피치

**「사냥꾼의 방주」** — *"죽이지 마라, 낚아채라. 적의 유전자를 훔쳐 최강의 혈통을 빚는 유일한 랜덤 디펜스."*

와일드카드 관점: 디펜스 장르의 유일한 동사 "죽인다"를 뒤집는다. **필드의 적이 곧 교배 자원**이다. 빈사의 적을 그물로 포획해 '야생 인자'를 뽑고, 그 인자를 출산에 주입하며, 최고의 자식 1기를 판을 넘어 '방주'에 보존한다. 랜덤 소환은 그대로 — 대신 소환된 재료를 무엇으로 키우느냐가 사냥으로 결정된다.

## 2. 코어 루프 변화 — 4박자에서 5박자로

| 박자 | 기존 | 변경 |
|---|---|---|
| Plan | 적 보고 빌드 결정 | + 라운드 배너의 "출현 인자 예보"를 보고 **사냥 계획**(어느 라운드에 그물을 쓸지) |
| Grind | 운+합성+자원 압박 | + **Hunt**: 빈사 적 포획 → 인자 획득 (그물 3발의 배분 긴장) |
| Pop | T4 완성 싹쓸이 | + **각성 출산**(변이×인자 잭팟) — Pop이 4분 한 번에서 판당 2~3회 분산 발생 |
| Loop | 다음 스테이지 | + **방주 계승**: 최고 유닛 1기를 다음 판으로, 단 패배 시 영구 사망 |

Pop 이후 "관전 모드"(문제 8)가 사라진다: T4 완성 후에도 다음 판에 물려줄 유닛을 고르고, 희귀 인자를 사냥하는 동사가 끝까지 남는다.

## 3. 핵심 시스템 변경 5개

### C-1. 포획 그물 — "죽이지 말아야 할 적" (문제 8, 7)
- **메커닉**: 적 HP 20% 이하 → 머리 위 🧬 표식 자동 점등. 하단 도크의 **그물 버튼(56×56px, 판당 3발)**을 누르면 화면 내 표식 적 중 HP 최저 1기가 포획(소멸+인자 드랍). 정밀 탭 불필요 — 버튼 1개로 처리(모바일 인체공학).
- **수치**: NORMAL/FAST/TANK 인자 = 흔함, ELITE 인자 = 희귀(GD3 미니보스 타이밍 활용), 보스 페이즈2 한정 **보스 인자** = 초희귀. 포획은 '적 한계 40' 카운트에서 즉시 제거 → *비상 밸브 vs 희귀 사냥 온존*이라는 결정이 매 라운드 발생.
- **재활용도**: **상** — 적 타입·ELITE·보스 페이즈 전부 기존 데이터. 신규는 표식 아이콘+버튼 1개+드랍 테이블.

### C-2. 인자 주입 교배 — 교배 약속의 이행 (문제 5)
- **메커닉**: 겹침 교배 3초 대기 중 보유 인자 슬롯(최대 5개 소지)에서 1개 탭 → 자식에 특성 각인. 예: NORMAL=피해+15%, FAST=공속+20%, TANK=공격 시 슬로우 20%/1.5s, ELITE=사거리+25%·피해+10%, 보스=30초마다 광역 폭발(피해 200%).
- **잭팟**: 기존 변이 15%와 **곱연산** — 변이+인자 동시 = **"각성 출산"**(수치: 인자 효과 ×1.5, 금빛 출산 연출 = 기존 T4 합성 플래시 재활용). 기회 2 "변이 잭팟 승격"을 수치 변경 0으로 흡수.
- 자식 이름에 인자 낙인 표기("늑대 [질주]") → 유닛이 처음으로 개체가 된다.
- **재활용도**: **중** — 교배 로직 존재, UnitData에 trait 1필드 추가. T2 기믹 12종 코드(체인/슬로우/스플래시)를 인자 효과로 그대로 전용 가능.

### C-3. 방주 — 판을 넘는 목숨 건 계승 (문제 6, 5)
- **메커닉**: 승리 시 생존 유닛 중 1기를 방주(초기 4칸)에 보존 — 인자·변이·이름 포함. 다음 판 시작 30초 내 **혈통 소환(30G)**으로 투입 가능. **단, 그 판 패배 시 해당 유닛 영구 사망**(도감에 묘비 기록).
- **수치**: 방주 확장 4→8칸은 💀영혼으로 구매(미사용 인자는 판 종료 시 💀5로 정산, 영혼 이월화) — 기회 4(영혼 영구화) 흡수. 패배해도 인자→💀 정산은 유지 = 지는 판에도 수확.
- 두 번째 판부터 "같은 산 같은 길"(문제 6)이 붕괴: 매 판의 목표가 "T4"에서 "내 방주를 어떻게 채우고 무엇을 걸까"로 개인화.
- **재활용도**: **중** — localStorage 저장 구조·도감 UI 확장. 신규 화면은 방주 1장.

### C-4. 라운드 언어 + 인자 예보 (문제 8, 3)
- 30초 보스 박동을 그대로 **"라운드 n"**으로 명명(기회 3). 라운드 시작 배너(GD1 컷인 축소판, 0.25s)에 "라운드 7 — 🧬FAST 출현" 예보 → Plan 박자에 사냥 계획이 얹힌다.
- GameOver 화면에 "라운드 12에서 적 한계 40 도달"을 대문짝 표기 → 죽음이 학습 가능해짐(문제 3 후반부).
- **재활용도**: **상** — 스크립트 웨이브 G4·컷인 GD1·브리핑 GD2 전부 재조립.

### C-5. 첫 세션 Pop 이식 — W1-3 "첫 사냥" (문제 4, 3)
- W1-3을 그물 튜토리얼로: 스크립트된 ELITE 1기가 자동 빈사 상태로 등장 → 그물 1발 무료 → **보스 인자 확정 드랍** → 주입 출산으로 T2가 광역 폭발을 뿜는 순간을 첫 3분 안에 체험(그 판 한정, 방주 보존 불가).
- 튜토리얼이 "검정 덮개+텍스트 19줄"에서 **행동 1회 = 학습 1개**(그물 버튼이 빛나고, 누르면 끝)로 전환.
- **재활용도**: **상** — W1 단계 해금 뼈대(건드리지 말 것 3) 위에 스테이지 1개 스크립트만 추가.

## 5. 기존 자산 재활용 맵

- **유닛 25종+아트**: 전량 유지, 인자 낙인은 틴트+칩 오버레이만.
- **적 스프라이트**: 인자 아이콘(초상 크롭)으로 2차 활용 → 신규 아트 0.
- **T2 기믹 코드 12종** → 인자 효과 엔진. **T4 합성 연출** → 각성 출산. **GD1 컷인** → 라운드 배너·포획 성공. **GD2 브리핑** → 인자 예보. **GD3 미니보스** → ELITE 인자 사냥 타이밍. **G4 웨이브 스크립트** → 라운드 넘버링. **도감/영혼상점/월드15** → 확장 수용체.
- 폐기 없음: 잘라내는 기존 시스템 0개.

## 7. 리스크와 완화책

1. **"죽이지 마라"가 T4 DPS와 충돌**(400 DPS가 표식 적을 즉살) → 그물 버튼은 표식 점등 후 **1.2초 포획 유예**(해당 적 무적 아님, 선착순). 놓치면 다음 라운드 예보로 재도전 — 오히려 긴장 요소로 전환.
2. **영구 사망 반발**(모바일 유저 손실 회피) → 혈통 소환은 항상 선택(안 꺼내면 안전), 사망 시 💀 30 위로금+묘비 서사화. W1은 방주 봉인.
3. **인자 밸런스 붕괴**(보스 인자 스택) → 유닛당 인자 1개·비상속, 보스 인자는 방주 보존 시 1칸을 2칸 차지.
4. **스코프 초과(1인 개발)** → M1~M2 우선 출하 가능 설계, 방주(M3)는 독립 모듈. 신규 화면 1장·신규 아트 아이콘 2종이 상한.
5. **포획이 적 한계의 치트키화** → 판당 3발 고정+라운드당 1발 캡, 밸브 용도로 쓰면 희귀 인자를 포기하게 되는 기회비용 유지.
