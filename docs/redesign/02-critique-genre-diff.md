# 장르 비평 & 차별화 전략 (랜덤 디펜스 전문가 관점)

근거: `01-understand-ux.md`, `01-understand-systems.md`, `01-understand-meta.md`, `01-understand-history.md` 인벤토리. 기각 목록(종족 선택 소환, 오버킬 연쇄, 각성 궁극기, 미리보기 고스트, 라스트 스탠드, 5G 리롤)과 겹치는 제안 없음.

## 1. 장르 필수 요소 체크리스트

| 요소 | 상태 | 근거 |
|---|---|---|
| 등급별 소환 연출 | ❌ | 소환은 텍스트 버튼 → 랜덤 위치 스폰. 등급 이펙트·연출 0 (UX §2). 잭팟(4% T2)조차 플래시+셰이크 80ms뿐 |
| 도박의 쾌감(리롤/천장/등급업 실패) | ⚠️ 절반 | 소환 RNG는 있으나 T1 6종 균등이라 "대박/쪽박" 낙차가 없음(시스템 §6). 잭팟이 유일한 낙차 |
| 최고 등급 목격 순간 | ⚠️ | T4 합성 시 흰 플래시 0.9+셰이크 500ms+햅틱은 있으나(UX §6), T4 스프라이트 미완성 — **이모지 🌟로 등장**(UX §7). 장르 최대 판매 포인트가 이모지 |
| 합성 트리 열람 | ✅ | RecipeBook, 미발견 ❓ 처리. 단 11px 텍스트 25줄, 스크롤 없음(UX §5) |
| 협동/경쟁(멀티) | ❌ | PvE 단독. 벤치마크 3종(랜덤다이스 PvP, 러시로얄 실시간 대전, 히어로즈 랜디 협동) 전부 멀티가 코어 |
| 리더보드/랭킹 | ❌ | 무한모드 기록이 9px 텍스트 한 줄, 랭킹·보상 연결 없음(메타 §3) |
| 웨이브 카운터·클리어 리듬 | ❌ | 웨이브 없음, 연속 스폰+타이머(시스템 §1). 아래 §3 |
| 일일/시즌 콘텐츠 | ❌ | GD4 일일 도전은 P3 미구현(히스토리 §4) |
| 유닛 수집·도감 | ✅ | 25종 도감+마일스톤 💎. 단 보상 총 6보석으로 종료(메타 §2) |
| 게이트/라운드 보상 선택 | ✅ | 30초 보스+카드 2~3장 — 장르 표준 이상으로 잘 됨 |

**진단**: 확률·합성·카드의 "시스템"은 장르 표준을 충족하지만, 이 장르의 감정 코어인 **연출(뽑기 낙차·최고등급 강림)과 사회성(랭킹·대전)이 통째로 없다.** 텍스트 버튼 45개·이모지 60+곳(UX §4·7)인 현 상태는 랜디 유저의 첫 30초 기대를 배반한다.

## 2. '교배' 기믹 냉정 평가

**현 구현 = 느린 소환 버튼이 맞다.** 근거: 자식은 "85% 동종 / 15% 동카테고리 변이"뿐(시스템 §6) — 부모의 스탯·특성·이름 무엇도 상속되지 않는다. 즉 교배는 "10초(교배5+탈진5) 기다리는 무료 소환"이고, 유저가 지각하는 차이는 골드 절약과 카테고리 필터링뿐이다. 소재(breeding)가 약속하는 유전·혈통·개체 애착이 코드에 존재하지 않는다.

**그러나 이건 결함이 아니라 미채굴 광맥이다.** 이 장르에서 교배를 코어로 쓴 상용작은 없다(랜덤다이스=합성, 러시로얄=머지, 운빨존많겜=뽑기). 게임의 얼굴로 만든 모습:

- **혈통(Lineage)**: 자식이 부모 세대 수를 상속 — n세대 유닛은 소환 불가·교배로만 획득, 세대당 소폭 보정. "이 판의 에이스는 내가 4번 교배해 만든 3세대"라는 서사가 생긴다. RNG 통제도(시스템 §6)의 "빌드 방향에 운이 작용 안 함" 한계를 교배축으로 해소.
- **변이의 낙차 연출**: 15% 변이를 현재는 구분 연출 없이 처리 — 변이 출산을 잭팟급 연출(금 플래시+전용 배너)로 승격하면 §1의 "도박 쾌감" 결핍을 기존 수치 변경 0으로 메꾼다.
- **특성 1슬롯 상속**: T2 기믹 12종(오라/체인/넉백/지뢰… 시스템 §3)이 이미 데이터로 존재 — 교배 시 낮은 확률로 부모 카테고리의 기믹 흔적 1개를 자식에 각인하면 "같은 T2도 족보 따라 다른" 개체 다양성이 생긴다. 기각된 '종족 선택 소환'과 달리 랜덤 묘미를 늘리는 방향.

핵심: **합성=확정 레시피(질서), 교배=혈통 RNG(카오스)**로 역할을 갈라야 이중 축이 선다. 지금은 둘 다 "재료 수급"으로 수렴한다.

## 3. 세션 구조 비교

상용 랜디의 리듬: **웨이브 n초 전투 → 클리어 → 정비 짬 → 다음 웨이브**. 이 단위가 (a) 진행률 체감("웨이브 24까지 감"), (b) 호흡(정비 타임), (c) 자랑 단위(랭킹=웨이브 수)를 전부 제공한다.

이 게임: 연속 스폰 7분 + 30초 보스 박동(시스템 §1). 어긋나는 지점 —
1. **진행률 언어 부재**: "남은 시간 4:12"는 성취가 아니라 대기. 웨이브 번호가 없으니 무한모드 기록도 "초 단위 텍스트"로만 남는다(메타 §3).
2. **호흡 없음 → 후반 관전 모드**: 정비 짬이 없는데 결정 밀도는 5~7분 구간 분당 2로 붕괴(시스템 §5). 상용 랜디는 후반일수록 웨이브가 굵어져 밀도가 오르는데 정반대.
3. **실패 비대칭**: 웨이브 게임은 "웨이브 31 도달"이 실패에도 성취로 남지만, 이 게임의 6분 붕괴(시스템 §4)는 6분 증발이다(메타 §4).
4. 30초 보스+스크립트 웨이브(G4)가 사실상 유사 웨이브 뼈대를 이미 갖고 있음 — **이 박동을 화면에 "라운드 n"으로 명명·카운트만 해도** 리듬 언어의 절반이 복구된다. 7분 구조 자체를 버릴 필요는 없다(승리 고정 시각은 '출퇴근 7분' 확정 결정, 히스토리 §1).

## 4. "___한 유일한 랜덤디펜스다" 후보 3

1. **"유닛을 뽑는 게 아니라 기르고 교배시켜 혈통을 만드는 유일한 랜덤 디펜스다."** — §2 방향과 정합, 소재 독점성 최대.
2. **"내 최강 유닛이 상점이 아니라 출산에서 나오는 유일한 랜덤 디펜스다."** — 스토어 카피로 즉시 사용 가능, 현 구현(교배로만 도달 가속)과도 거짓 없이 부합.
3. **"운을 뽑기가 아니라 육종(育種)으로 통제하는 유일한 랜덤 디펜스다."** — 코어 유저 소구. 단 현재는 통제 수단이 영혼소환뿐이라(시스템 §6) §2 확장이 선행돼야 참이 된다.

## 5. 스토어 스크린샷 5장 테스트

지금 찍으면: ① 타이틀=단색 배경+텍스트(UX §1) ② 인게임=이모지 적 👾🐝 + 텍스트 HUD "Gem:/Gold:" 영문 라벨 ③ T4=이모지 🌟 ④ 팝업=monospace 텍스트 패널 ⑤ 스테이지 선택=텍스트 버튼 16개. **5장 중 팔리는 장면 0장.** NovelAI 스프라이트 18종이 유일한 자산인데 40~52px라 스샷에서 안 보인다.

필요한 5장과 결손:
| # | 장면 | 현 결손 |
|---|---|---|
| 1 | 교배 순간(하트+출산 연출 클로즈업) | ❤ 이모지 1개뿐 — 전용 연출 없음 |
| 2 | T4 Astral_God 강림+8타겟 섬멸 | T4 스프라이트 미완(히스토리 §4 아트 잔여) |
| 3 | 합성 트리 한눈에(6→12→6→1) | RecipeBook이 11px 텍스트 — 비주얼 트리 없음 |
| 4 | 보스 카드 선택(빌드하는 손맛) | 카드가 파랑 배경 텍스트(UX §5) — 카드 일러스트 없음 |
| 5 | 도감/혈통 컬렉션 | 도감 UI 자체가 스샷 가치 없는 텍스트 |

결론: 스토어 자산 이전에 **인게임이 스스로 스샷이 되게** 만드는 순서 — T3/T4 스프라이트(이미 예정) > 교배 출산 연출 > 카드 비주얼 > 레시피 트리 그래픽.

## 종합 우선순위

1. 교배를 얼굴로: 변이 연출 승격(코드 최소) → 혈통/특성 상속(중기).
2. 30초 보스 박동을 "라운드"로 명명해 웨이브 언어 확보.
3. 소환·T4 등장 연출을 장르 표준(등급 낙차)으로.
4. 무한모드 기록 → 리더보드화(GD4 일일 도전과 결합).
