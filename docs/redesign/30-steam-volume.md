# Steam 1.0 볼륨 설계 — 실질 5h+ 예산표 (디벨롭 2회차)

> 2026-07-09. 29번 §3 S-C(볼륨) 전담 회차. 원칙: **볼륨은 판을 늘려서 만들지, 판을 늘어뜨려서 만들지 않는다**(헌법 1조 7분 문항 — 세션 7분 불변, 판 수·모드·목표의 곱으로 시간을 산다).
> 부수 효과: M4에서 이연된 미결 항목 **"결과 카드 별점(⭐) 기준"을 여기서 확정**(§2) — 별점이 곧 볼륨 승수라서 이 회차의 소관이 맞다.

## 1. Steam 1.0 콘텐츠 경계 (스코프 확정)

> "Steam 1.0" = 모바일 v1.0(M5 완주)과 **같은 코드베이스**에서 G 시리즈+아래 항목을 얹은 빌드. 모바일 v1.1과 사실상 동일 범위 — 즉 Steam이 요구하는 볼륨을 먼저 만들고 모바일이 그걸 물려받는 순서.

| 포함 | 근거 (기존 문서) |
|---|---|
| M5 — 가문·도감·타이틀 | 기획 완료분 |
| **별점 45개** (15스테이지×3) — §2 신설 | M4 이연 미결 항목 해소 |
| G2 적 3종 (실드·분열·힐러) | 빌드 분기 성립 조건 (21번) |
| G3 BGM 3트랙 | Steam 최저선 (29번 S-G) |
| G4 일일 시드 런 — §4에서 Steam형으로 재해석 | 21번 승격분 |
| G1 주간 시드 + 리더보드 (Firebase 공유 = 크로스플랫폼 경쟁이 셀링 포인트) | 21번 |
| G5+S-E 클라우드 세이브·도전과제 15~30개 | 29번 |
| **L1 유파 승격** — 28번 카탈로그 6유파 그대로 | 유닛 0종 추가로 이론작 축 확보 (23번 L1) |
| 무한 모드 정식화 「가문 시험」 — §3 | 기존 isInfiniteMode 심화 |

**제외 확정 (= 헌법 2조의 '뺄 것')**: L3(신들의 대립)·L4(침공)·L5(월드 4)·L6(시즌틀)·Ruin_God은 Steam 1.0 범위 밖 — 라이브 업데이트 자산으로 보존(23번 캘린더 유지). 특히 **월드 4를 빼는 것**이 별점 45개 추가와의 맞교환이다: 신규 스테이지 5개(아트 다수)보다 기존 15개×3목표(아트 0장)가 볼륨/비용비 3배 이상.

## 2. 별점(⭐) 기준 확정 — 볼륨 승수이자 결과 카드 미결 해소

> M4 메모 "별점 산정 기준이 어느 문서에도 없음 — 착수 전 설계 결정 필요"의 정식 답. 모바일에도 동일 적용(Steam 전용 아님).

| 별 | 기준 | 설계 의도 |
|---|---|---|
| ⭐ | 승리 (기존 승리 조건) | 진행 게이트 — 현행 유지 |
| ⭐⭐ | **정점 유닛 Gen3+ 로 승리** | 세션 목표(v3 R4 "Gen3 T4")를 명시적 목표로 승격 — 교배 시스템 강제 노출 |
| ⭐⭐⭐ | **스테이지별 고유 혈통 도전 1개** | Plan 박자 — 스테이지 브리핑에서 미리 공지, 빌드를 바꾸게 만드는 조건만 |

- ⭐⭐⭐ 조건 풀 (15스테이지에 배정, 아트 0장·전부 기존 시스템 판정): 이계열 교배 N회 이상 승리 / 특정 계열 혈통 정점으로 승리 / 변이 유닛 3기 이상 보유 승리 / 교배 예산 3회 이하로 승리 / 판매 N회 이하 / 특성 보유 정점으로 승리 / 혈통 일격 누적 N회 등.
- **금지**: 시간 단축형("N분 내 클리어") — 7분 리듬을 러시로 왜곡. 무피해형 — 낙차(피격→만회)를 죽임.
- 헌법 3문항: 박자=Plan 강화 / ⭐⭐·⭐⭐⭐ 전부 교배·혈통 조건 = 낳는 게임 강화 / 7분 불변. 첫 15분 개념 추가 없음(별점은 결과 카드에서만 노출, W1-1은 ⭐ 하나만 표시해 점증).
- 보상: 별 누적 = 도전과제 연동 + 가문 전당 장식(코스메틱). **💀·💎 지급 안 함** — 파밍 루프화 방지(뺄 것: 별점 재화 보상).
- 볼륨 기여: 캠페인 1회 완주(⭐) 후 ⭐⭐·⭐⭐⭐ 회수가 "같은 스테이지, 다른 빌드" 재방문 15~30판 생성.

## 3. 무한 모드 정식화 — 「가문 시험」

- 현행: `isInfiniteMode`로 승리 판정만 끄고 OVERTIME 라운드 무한 누적 — 기록·보상·스케일링 설계가 없다.
- 정식화: 15라운드부터 적 HP/수 스케일링 곡선(12번 시뮬로 산출, 상수는 3조 프로토콜로 1개씩) + **점수 = 도달 라운드 + 정점 Gen×가중 + 변이 등급 보너스** — 점수식이 "더 버티기"가 아니라 "더 좋은 혈통 만들기"를 보상하게.
- 진입: 캠페인 W1 클리어 시 해금, 스테이지 선택 화면 별도 탭. G1 주간 시드·G4 일일 런의 **공용 무대**가 된다(모드 하나로 3콘텐츠).
- 헌법: 7분 문항 예외 아님 — 무한 모드는 "판 밖 대기"가 아니라 판 자체가 길어지는 **선택** 모드, 별도 탭 격리(23번 L4와 같은 원칙).

## 4. 일일·주간의 Steam형 재해석 (FOMO 제거)

- 모바일 GD4: 일일 클리어 💎1 (리텐션 장치) — 유지.
- **Steam판: 보상 재화 제거, "오늘의 시드 런" 기록 경쟁만** — 프리미엄 유저에게 일일 숙제 감성은 리뷰 감점. Slay the Spire 데일리 클라임 모델: 같은 시드, 리더보드, 끝.
- 주간 시드(G1)는 양 플랫폼 동일 — Firebase 리더보드 공유로 "모바일 유저와 같은 시드 경쟁"이 Steam 상점 문구가 된다.
