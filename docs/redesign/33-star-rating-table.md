조건 풀 7종 전부 소화, 각 유형 점증(변이 1→3→5, 이계열 2→4, 예산 3→2, 일격 20→40). 3계열(검·야수·강철) 각 1회 "정점 계열" 도전 = 특화 플레이 보상. 조건은 해당 기능 해금 직후 배치.
