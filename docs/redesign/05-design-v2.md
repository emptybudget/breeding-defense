# 재설계 기획서 v2

> v1 대비 변경 핵심: ① Gen을 연속 %에서 **눈에 보이는 이산 전투 표현**(혈통 일격+오라)으로 교체, ② 교배 경제 수치 명문화(부모 소모·판당 예산 6회) + 합성 Gen 계승 **평균→최대치**로 변경 + 세션 목표 **Gen3 T4**로 재산정(산술 검증 포함), ③ 프리징 버그를 하드 게이트에서 **타임박스 계측+소킹 판정 병렬 트랙**으로 전환, ④⑤ **둥지 상시 패널 폐기 → 독 변신 문법 통일**로 수직 예산 136px 확정, 트랙 무변경이 산술적으로 성립.

## 2. 비전

**한 줄 피치**: "뽑는 게임이 아니라 낳는 게임 — 당신이 교배로 길러낸 혈통이 신(神)을 낳는, 유일한 랜덤 디펜스."

**디자인 필러 3개**
1. **혈통은 눈으로 보인다** — Gen은 스탯 시트가 아니라 화면 위의 오라·추가 타격이다. 숫자는 뒷면 구현일 뿐.
2. **팔리는 몸 위에서** — 44pt·엄지존·낙차 연출을 갖춘 모바일 쉘. 스샷 5장 전부 교체 가능이 기준선.
3. **판이 이어진다** — 가문 계승·영혼 이월로 "오늘 켤 이유"를 만든다.

## 3. 시스템 재설계

### R1. JuicyButton 리스킨 + 한손 커맨드 독 — P3
- 공용 `JuicyButton`(Graphics: 라운드 8px+금테+음영, 눌림 scale 0.94/80ms+햅틱)으로 45버튼 치환. **히트영역은 생성자에서 코드로 강제 — 48px 미만 지정 시 clamp**(개발 빌드는 throw). 폰트 WebFont 1종 서브셋+숫자 비트맵.
- **수직 예산 확정(산술 검증)**: 상단 바 44px / 필드 y44~548(504px) / 커맨드 독 92px(y548~640). config.ts 트랙은 y90~520이므로 독 상단(548)과 28px 여유 — **트랙·배치존·사거리 무변경이 실제로 성립**. 둥지 상시 패널(88px)은 폐기(R7).
- 독 구성: 중앙 소환 96×64(비용 뱃지), 좌 한도+1, 우 영혼상점 56×48. ⏸ 등 저빈도 우상단 48×48. 전 버튼 `pointerup`+슬롭 8px.
- **드래그 컨텍스트 모드**: 유닛 드래그 시작 시 독이 변신 — 중앙에 둥지 슬롯 2개(56×56), **판매 존은 좌우 가장자리(각 48px)로 분리**. 시각=판정 동일 상수. **Gen1+ 또는 특성 보유 유닛 판매는 0.3s 홀드 게이지 필수**(오판매=비가역 손실 차단).
- 드래그 대안: **유닛 탭 → 바텀시트 '둥지로' 버튼** 2탭 경로 병행(필드 최상단 유닛 한손 조작 커버).
- **상단 바 폭 예산표**: 라운드 세그먼트 바 60px + "9/14" 텍스트 28px + 타이머 40px + 카운트 링 32px + 재화 칩 2×52px + 간격 6×8px = **312px ≤ 360px**. 핍 14개 개별 렌더는 폐기.
- **오버레이 세이프존 규칙**: 배너·예상 혈통 카드·부화 연출은 y100~420, 중앙 폭 320px 내에만 배치.

### R2. 라운드 언어 + 소환 낙차 연출 — P5·P4
- 30초 보스 박동을 "ROUND n" 명명(14라운드). 세그먼트 바+숫자, 라운드 배너 0.6s, 클리어 "+5G" 스탬프(총 +70G, 폴백 스위치). GameOver "라운드 9 도달 — 최고기록 11".
- 소환/부화 공통 카드 뒤집기 0.35s: 일반=흰 플래시 / **금빛 빔은 희귀 변이 이상 전용**. T2 잭팟(4%)은 백금 플래시로 강등 — 2분 뒤 합성으로 공짜인 것에 팡파레 화폐를 낭비하지 않는다.

### R3. FTUE + 패배 학습 + 첫 세션 Pop — P5·P4
- 19줄 덮개 폐기. 스포트라이트+손가락 고스트+강제 1회 수행. **FTUE는 마일스톤별 분산 제작**: 각 M의 완료 판정에 "해당 M 신규 기능의 FTUE 스텝 포함"을 기재. M2는 M2 시점 존재 인터랙션 7종만, 교배 스텝은 M4에서 둥지와 함께 1회만 제작.
- 적 한계 32px 카운트 링(n/40, 32부터 붉은 맥동+햅틱), GameOver 1행 "패배 원인: 적 40마리 초과"+팁.
- 2배속 W1 무료 기본화. W1-5 클리어 시 T4 컷인.
- **첫 세션 확정 잭팟**: W1-2 최초 1회 교배는 **희귀 변이 확정 롤**(내부 조작, 이후 정상 확률) — 잭팟이 예고편이 아니라 첫 세션 게임플레이 안에서 반드시 터진다.

### R4. 혈통 세대(Gen) — P1·P2 【전면 개정】
- `gen: 0~4`(캡 4로 하향). 소환=Gen0, 교배 자식=`max(부모 Gen)+1`. **교배는 부모 2마리를 소모**하고 알 3초 후 자식 1마리. **판당 교배 예산 6회**(소진 시 둥지 비활성) — 소환 골드와 트레이드되는 자원이자 시뮬 검증의 상한.
- **Gen의 전투 표현은 이산적**: Gen1=금빛 오라 링 / Gen2=오라+**혈통 일격**(공격 4회당 1회, 금색 추가 발사체) / Gen3=3회당 1회+오라 2겹 / Gen4=2회당 1회+스케일 1.15+오라 맥동. 뒷면 수치: 혈통 일격=해당 공격 데미지 100% 추가타(Gen2 +25% ~ Gen4 +50% DPS). **+8% 연속 보정과 10px 이름표는 폐기** — 이름은 탭 바텀시트에서만 노출.
- **합성은 재료 중 최대 Gen을 계승**(평균·희석 폐기). 질서 축(합성)은 Gen을 만들지 못하고 보존만 한다 — 교배만이 Gen을 올린다는 축 분리가 오히려 선명해짐. **합성 UI에 결과 Gen 사전 표기**("Gen0+Gen3→Gen3").
- **세션 목표: Gen3 T4** (Gen4는 무한모드·가문 장기 목표). **산술 검증**: Gen3 T1 1마리 = 교배 3회(G0+G0→G1, G1+G0→G2, G2+G0→G3), Gen0 4마리 소모, 알 9초+드래그 6회 ≈ 실행 40초. 최대 계승이라 이 1마리를 합성 라인에 태우면 T4까지 Gen3 보존 — T4 도달 4~5분 타이밍과 교배 예산 6회(3회 소요, 3회는 특성·변이 도박용) 안에 성립. M3 시뮬 테스트에 이 행동 시퀀스를 명시 포함(§6).

### R5. 특성 1슬롯 상속 — P1
- T2 기믹 12종을 `trait`로 승격, T1 슬롯 1개. 상속 50%/40%+제3 무작위 20%, 합성 60% 계승. **해금은 W1-4 → W2-1로 이연** — W1 첫 세션은 소환·합성·교배(Gen·변이)만. 첫 세션 예상 혈통 카드는 숫자 2개(Gen·변이%)로 시작, 특성 해금 후 3개로 점증.

### R6. 변이 3등급 잭팟 — P4·P1
- 총 15% 분해: 일반 12% / 희귀 2.5%(Gen+2) / 전설 0.5%(특성 2슬롯+금빛 이름). 부화 0.4s 프리즈→등급색 플래시→셰이크+배너+햅틱.
- **소프트 피티**: 교배 8회 연속 무희귀 시 희귀 확률 10%로 상승(발동 후 리셋), 전설은 계정 누적 60회 피티 — 판당 교배 ≤6회 예산 하에서도 2~3판마다 희귀가 체감된다.
- **변이 자식은 레시피 와일드카드**(합성 재료로 동종 취급) — 일반 변이가 합성 계획을 망치는 꽝이 되지 않는다.

### R7. 둥지 — P1·P3·P5 【상시 패널 폐기】
- "겹치기 교배" 폐기 유지. **상시 88px 패널도 폐기** — 둥지는 R1의 드래그 컨텍스트 모드(독 변신) 안에 산다. 평시 크롬은 상단 44+독 92=136px, 필드 504px 보존.
- 슬롯 1 투입 시 독에 24px 접힘 탭(알 실루엣+금빛 펄스)으로 상태 표시, 2슬롯 차면 **예상 혈통 카드**(세이프존 내)→교배 버튼 64×48→3초 알→부화. W1-2 금빛 펄스로 자가 발견.

### R8. 가문 계승 메타 — P2
- 판 종료 시 최고 Gen 유닛 1마리 "가문" 등록(종·Gen·특성·이름). 이월 💀로 가문 알 구매(Gen1=💀3, Gen2=💀8, 상한 Gen2 고정). 2차 트리 2종: 특성 상속률 +5% / 희귀 변이 +0.5%.

### R9. (v1.1 예비) 야생 인자 — 변경 없음, 범위 밖.

### 빼는 결정 (v2 누적)

## 6. 마일스톤 로드맵 (각 M 끝 사용자 플레이테스트 게이트)

### M1. 제품 쉘 (난이도: **중**, 소→중 재산정)
- 포함: R1 전체 — 수직 예산 확정(44/504/92)+JuicyButton+독+드래그 컨텍스트 모드(둥지 슬롯·가장자리 판매존·홀드 확인)+2탭 경로+카운트 링. 독이 76→92px로 16px 늘지만 트랙(y520)과 28px 여유 확인 완료 — 트랙 무변경.
- 완료 판정: `npm run build` / Text버튼 grep 0건 / **JuicyButton 외 `setInteractive` 직접 호출 grep 0건** / 생성자 clamp 유닛 테스트 / 판매존 시각=판정 동일 상수.
- 게이트: 한손 조작감 + **"필드 최상단 유닛을 한손으로 둥지 슬롯에 투입" 시나리오** + 오발·오판매 소멸 확인.

### M2. 리듬과 낙차 (난이도: 중)
- **선결(타임박스 2일): 프리징 버그 계측 강화만** — 프레임 워치독+링버퍼 로그를 `#fatal-error` 오버레이에 덤프. **'해결' 판정은 소킹 기준(사용자 연속 10판 무재현)으로 정의**하고 M2 연출 작업과 병렬 진행(신규 연출은 트윈 풀 재사용으로 악화 방지). 하드 게이트 아님 — 크리티컬 패스에서 제거.
- 포함: R2+R3(M2 시점 존재 인터랙션 7종 FTUE·패배 사인·2배속 무료·T4 컷인).
- 완료 판정: 유닛 테스트(라운드 경계·+70G·연출 분기) / 텍스트 덮개 미출현 / GameOver 원인 문구.
- 게이트: "죽은 이유를 팝업만 보고 말할 수 있는가".

### M3. 혈통 데이터층 (난이도: 중)
- 포함: R4+R5+R6 데이터·판정부(gen/trait, max 계승, 예산 6회, 피티, 와일드카드). 렌더 무변경.
- 완료 판정: 순수 TS 테스트 — 상속·Gen 전파·피티 / 등급 분포 1만회 시뮬 **등급별 상대 오차 ±20%**(±1%p 폐기 — 전설 0.5%가 3배 뻥튀기돼도 통과하는 기준이었음) / **"7분 행동 예산 시나리오" 테스트: 교배 6회·부모 소모·알 3초 규칙 하에 Gen3 T4 도달 시퀀스가 존재하고 소요 행동 수가 예산 내임을 시뮬로 증명** / `npm run build`.
- 게이트: W2-5 풀플레이 회귀 없음.

### M4. 혈통의 무대 (난이도: 중)
- 포함: R7(독 둥지 모드+예상 혈통 카드+접힘 탭)+R6 연출부+W1-2 확정 희귀 롤+바텀시트 혈통 표기+결과 카드+혈통서+**교배 FTUE 스텝(최초·유일 제작)**.
- 완료 판정: 빌드 / 알 3장 적용 / 세이프존 좌표 상수 테스트 / 교배 FTUE 포함.
- 게이트: "설명 없이 둥지 발견 가능한가" + 첫 세션 잭팟 체감 + Gen 오라·혈통 일격이 눈으로 구분되는가.

### M5. 가문 계승 + 밸런스 + 잔여 리스킨 (난이도: 대)

## 7. 리스크 레지스터 + 비즈니스 모델 노트

| 리스크 | 심각도 | 완화책 |
|---|---|---|
| 프리징 버그 장기화 | 높음 | 타임박스 계측+소킹 판정, 병렬 트랙이라 로드맵 정지 없음 |
| 혈통 일격(최대 +50%)이 긴장감 파괴 | 높음 | 주기 파라미터 1개로 즉시 튜닝 가능, M5 게이트 재측정 |
| **혈통 유닛 오판매(비가역 손실)** | 높음 | Gen1+/특성 유닛 0.3s 홀드 확인+판매존 가장자리 분리 |
| FTUE 과부하 | 중 | 특성 W2 이연, 카드 숫자 2→3 점증, 합성 결과 Gen 사전 표기, M별 분산 제작 |
| 가문 알 스노우볼 | 중 | Gen2 상한·💀 커브, 이상 시 W3 봉인 |
| Gen 회귀 표면 | 중 | M3 데이터층 격리, 시뮬 상시 회귀 스위트 |
| 교배 예산 6회가 답답함 유발 | 저 | 상수 1개, M4 게이트에서 8회로 확장 여지 |
| 폰트·에셋 로드 | 저 | 서브셋·WebP·지연 로드 |

**비즈니스 모델 노트**: 스샷 5장 교체+ASO "출산에서 최강 유닛이 나오는 유일한 랜덤 디펜스". 첫 세션 확정 희귀 잭팟은 스토어 영상 소재. 가문 슬롯 IAP / 💀→💎 싱크 / 광고 "전설 확률 +0.5% 24h" / 혈통 카드 공유. v1.1: 신규 특성=패치 1회, 야생 인자, 가문 리그.

### 반론 해소 기록
1. **Gen 체감 불가** → Gen을 연속 +8%에서 이산 전투 표현(단계별 오라+공격 n회당 금색 추가 타격 '혈통 일격')으로 교체, 숫자는 뒷면 구현으로만 존치, 10px 이름표 폐기(R4).
2. **Gen4+T4 산술 미검증** → 부모 소모·알 3초·판당 예산 6회를 수치로 명문화, 합성 계승을 평균→최대로 변경, 목표를 Gen3 T4로 하향, 도달 시퀀스(교배 3회·Gen0 4마리·~40초)를 기획서에 계산해 박고 M3 시뮬 테스트로 강제(R4·M3).
3. **프리징 하드 게이트** → 타임박스 2일 계측(워치독+링버퍼→오버레이 덤프)만 선결, '해결'은 소킹 기준(연속 10판 무재현)으로 정의, M2 작업과 병렬화(M2).
4. **하단 180px가 트랙과 충돌** → 둥지 상시 패널 폐기·독 변신 문법으로 흡수, 하단 예산 92px 복귀 — 독 상단 y548 vs 트랙 하단 y520으로 28px 여유를 산술 확인, 트랙 무변경 성립, M1 난이도 중으로 재산정(R1·R7·M1).
5. **크롬 224px 필드 압축** → 평시 크롬 136px(상단 44+독 92)로 축소, 필드 504px 보존, 오버레이 세이프존(y100~420·폭 320) 규칙과 상단 바 폭 예산표(합 312px) 명시(R1·§4).
