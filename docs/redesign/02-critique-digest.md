# 비평 다이제스트 — 재설계 발산의 유일한 컨텍스트

4개 비평(모바일 UX·장르 차별화·판타지/FTUE·리텐션)의 관통 진단. 모든 근거는 01-* 인벤토리 기반.

**한 줄 총평**: 게임의 "몸"(전투 연출·시스템·아트 자산)은 상용급인데, "옷"(UI 크롬·온보딩)은 개발자 터미널이고, "심장"(교배라는 소재의 약속)은 코드에 아직 없다.

## 1. 문제 톱 8

| # | 문제 | 근거 | 심각도 |
|---|---|---|---|

| 2 | **터치 인체공학 실패** | ⏸/📖 실측 27×19px(44pt 규칙의 절반 이하), 상단 배치로 엄지 사각지대, 전 버튼 `pointerdown` 즉발, 판매존 표시≠판정 영역 | 치명 |

| 4 | **첫 세션에 Pop이 없다** | 핵심 쾌감 T4(400 DPS, T3의 25배)는 4~5분차 W2-5 기준 — W1 첫 세션 상한은 T2. 2배속마저 3보석 메타 구매라 이탈 최다 구간 유저가 가장 느린 버전을 플레이 | 치명 |
| 5 | **교배 = 느린 소환 버튼** (소재 약속 미이행) | 자식은 85% 동종/15% 변이뿐, 부모의 스탯·특성·이름 무상속. 유닛은 이름·개체구분·판간 성장 없는 소모품 — 유전·혈통·애착이 코드에 부재. 변이 15%조차 구분 연출·로그 0 | 치명 |
| 6 | **Loop/영구 진행 붕괴** | 최종 목표 항상 T4 1종(두 번째 판부터 같은 산 같은 길), 메타 총 14보석으로 종료, 승리 팝업에 다음 목표 제시 0, W2/W3 해금 미구현(`isWorldUnlocked()` W1만)이라 프로덕션 실콘텐츠 14분 | 치명 |
| 7 | **장르 감정 코어·사회성 부재** | 소환 등급 연출 0(T1 6종 균등이라 낙차 없음), 리더보드·PvP·협동 0(벤치마크 3종 전부 멀티 코어), 일일/시즌 콘텐츠 미구현(GD4 P3) — "오늘 켤 이유" 0개 | 높음 |

## 2. 기회 톱 5 — 재설계가 반드시 활용할 것

1. **교배 광맥**: 이 장르에서 교배를 코어로 쓴 상용작 없음. 혈통(세대 상속, n세대는 교배로만), 특성 1슬롯 상속(T2 기믹 12종이 이미 데이터로 존재), 변이 기록 — "출산에서 최강 유닛이 나오는 유일한 랜덤 디펜스"라는 독점 포지션. 합성=확정 레시피(질서) vs 교배=혈통 RNG(카오스)로 이중 축 성립 가능.
2. **변이 15%를 잭팟 연출로 승격**: 수치 변경 0으로 장르의 "도박 낙차" 결핍을 메꾸는 최소비용 카드.
3. **30초 보스 박동 = 유사 웨이브 뼈대**: 화면에 "라운드 n" 명명·카운트만 해도 리듬 언어 절반 복구 — 7분 구조는 건드리지 않고 해결.
4. **영혼(💀) 영구화 + 도감 서사화**: 판내 화폐 영혼을 이월시켜 2차 트리(미결정 항목과 합치)를 달면 장기 파워 커브·보석 싱크·수익화가 동시에 열림. 도감에 혈통/변이 기록을 얹으면 수집욕 표면 확보.
5. **저비용 리스킨 자산 이미 보유**: artnouveau.ts 벡터 패널(금테+덩굴)+NovelAI 파이프라인(18종 확립, 스킨 한계비용 낮음)+공용 `JuicyButton` 래퍼 1개로 45버튼 일괄 해결 — 문제는 에셋 부재가 아니라 미적용.

## 3. 절대 건드리지 말 것 3

1. **전투 주스** — 셰이크·플래시·히트프리즈·5단 햅틱은 이미 상위권. T4 합성 연출(플래시 0.9+셰이크 500ms)도 최대치.
2. **7분 고정 세션 + 30초 보스 카드픽(2~3장)** — '출퇴근 7분'은 확정 결정 사항(히스토리 §1)이고, 게이트 보상 선택은 장르 표준 이상으로 잘 됨.
3. **W1 단계별 기능 해금 뼈대 + 고정 레시피 합성 트리(6→12→6→1)** — 온보딩 구조와 학습 가능한 질서 축은 건전. 문제는 전달 방식이지 구조가 아니다.

## 4. 제약 리마인더

기각 목록과 겹치는 제안 금지: 종족 선택 소환, 오버킬 연쇄, 각성 궁극기, 미리보기 고스트, 라스트 스탠드, 5G 리롤. 랜덤 소환 유지가 전제.
