# 유파(流派) 카탈로그 초안 — L1 특성 세트 시너지 (v1.1 분기1)

> 2026-07-06. 특성 = T2 기믹 12종(R5). **필드에 두 특성의 보유 유닛이 동시 존재**하면 유파 성립 — 유닛 소유가 아니라 필드 조합이라 배치가 결정이 된다. 성립 시 정점 유닛 문장에 유파 인장(Graphics) + 배너 1회. 수치는 초안 — 구현 시 12번 방법론 시뮬 필수.

| 유파 | 구성 특성 (원 기믹) | 세트 효과 | 노림수 |
|---|---|---|---|
| **일격문(一擊門)** | 광전사 스택(Blade_Hound) + 근접 인파이터(Bio_Wolf) | 혈통 일격 주기 −1 (Gen2 4→3회당…) | 근접 혈통 빌드의 정점 — 일격 시스템과 직결 |
| **포화문(砲火門)** | 스플래시(Gatling_Dog) + 멀티샷(Missile_Gunner) | 스플래시 반경 +30% | 물량전 특화 — G2 분열 적 카운터 |
| **뇌전문(雷電門)** | 체인(Electric_Coon) + 관통(Laser_Sniper) | 체인 최대 대상 +1 | 직선+연쇄 하이브리드 |

- 12특성 = 6유파 × 2, **전 특성이 정확히 1개 유파에 소속** (사각 없음). 동시 성립 상한 2유파 (초과 시 먼저 성립한 순).
- UI: 성립 순간 배너("일격문 개파!") + 도감에 유파 탭. 해금은 특성 시스템(W2-1)과 동시 — 표기만, 효과는 L1 패치에서 활성.
- 밸런스 가드: 세트 효과는 **원 기믹의 증폭만** (신규 메커닉 금지 — 시뮬 가능성 유지). 일격문이 최강이어야 함(혈통 정체성) — 나머지는 상황 우위.
- 테스트: 성립/해제 판정(유닛 사망·판매 시 즉시 재평가), 2유파 상한, 각 유파 DPS 기여 시뮬.
- 명명 규칙: 「~문(門)」 — 세 문(門) 세계관과 접속: *"여섯 유파는 세 문이 갈라지기 전, 하나의 도장에서 나왔다"* (26번 설정집 낙수 소재).
