# 신규 SFX 스펙 (명가 패치) — Web Audio 파라미터

> 2026-07-06 확정. 구현: `src/scenes/SoundManager.ts`의 기존 `tone(ctx, type, f0, f1, vol, start, dur)` 헬퍼 재사용 — 새 오디오 인프라 불필요. 각 스펙은 tone() 호출 시퀀스로 기술한다.
> 등급 사운드 원칙: **음 개수·상행 폭 = 등급** (일반 2음 < 희귀 4음 < 전설 6음+트레몰로). 부화 3종은 앞 0.15s가 동일(게이지 완료음) — 등급은 그 뒤에서 갈린다(낙차 보존).

## SFXType 추가

```ts
export type SFXType = /* 기존 7종 */ | 'button' | 'nest' | 'eggTick' | 'hatchCommon' | 'hatchRare' | 'hatchLegend'
  | 'roundClear' | 'strike' | 'familyRegister' | 'holdConfirm' | 'cardFlip';
```

## 스펙 (t = ctx.currentTime)

| 타입 | 트리거 (M) | tone() 시퀀스 | 의도 |
|---|---|---|---|
| `button` | JuicyButton 눌림 (M1a) | `('square', 660, 660, 0.06, t, 0.03)` 단발 | 초저볼륨 틱 — 45버튼 전부라 존재감 최소 |
| `nest` | 둥지 슬롯 투입 (M1b) | `('sine', 392, 523.3, 0.15, t, 0.09)` | 포근한 상행 — "안착" |
| `eggTick` | 알 게이지 1초마다 ×3 (M4) | `('triangle', 880+i*110, 동일, 0.08, t, 0.05)` i=0,1,2 회차 | 심장박동 카운트업, 기대 조성 |
| `hatchCommon` | 일반 부화 (M4) | `('sine',523,523,0.2,t,0.15)` → `('sine',659,659,0.18,t+0.08,0.12)` | 2음 — 탄생 확인, 과장 금지 |
| `hatchRare` | 희귀 부화 (M4) | 공통 앞부분 + `[523,659,784,1047]` sine 0.22, i*0.07 간격, 각 0.13 | 4음 상행 아르페지오 — 기존 sfxSynth 문법 계승 |
| `hatchLegend` | 전설 부화 (M4) | 앞부분 + `[523,659,784,1047,1319,1568]` sine 0.26, i*0.06 + 마지막 음 `('sine',1568,1568,0.2,t+0.36,0.5)` 롱테일 + 동시에 `('triangle',3136,3136,0.06,t+0.36,0.5)` 배음 반짝임 | 6음 팡파레+여운 — 세션 최고 낙차 |
| `roundClear` | 라운드 스탬프 (M2) | `('square', 784, 988, 0.12, t, 0.07)` | 짧은 도장 소리 — 14회 반복돼도 안 질리게 1음 |
| `strike` | 혈통 일격 (M4) | `('sawtooth', 220, 880, 0.14, t, 0.08)` | 금색 추가탄 전용 상행 슬라이드 — kill(하행)과 대칭 |
| `familyRegister` | 가문 등록 (M5) | `[261.6,329.6,392,523.3]` sine 0.22, i*0.09, 각 0.3 | 기존 victory 코드톤 축소판 — "기록됨"의 장중함 |
| `holdConfirm` | 0.3s 홀드 판매 완료 (M3/M4) | `('triangle', 500, 300, 0.15, t, 0.12)` | 하행 = 떠나보냄. 홀드 중엔 무음(게이지 시각만) |
| `cardFlip` | 카드 뒤집기 (M2) | `('triangle', 1200, 1600, 0.1, t, 0.05)` | 종이 스냅 — 소환·부화 카드 공용 |

## 규칙

- **볼륨 위계**: hatchLegend(0.26) > hatchRare/familyRegister(0.22) > hatch공통/strike(≤0.2) > UI음(≤0.12) — 잭팟이 항상 가장 크다.
- `strike`는 다타겟 동시 발동 시 **80ms 스로틀** (기존 크리 햅틱 1.5s 스로틀과 같은 패턴, 귀 피로 방지).
- `button`은 뮤트 상태에서도 햅틱만 유지 (기존 `_muted` 분기 그대로).
- 부화 3종 테스트: 눈 감고 등급 구분 가능해야 함 — 사용자 게이트(M4)에 포함.
- 구현은 전부 `playSFX` switch 확장 + private 메서드 11개 — 파일 1개 수정으로 완결, 순수 TS 테스트 불필요(렌더 레이어), build만.
