# breeding-defense UI/UX 인벤토리 (사실 기반)

기준 해상도: 360×640 (config: GAME_WIDTH=360, GAME_HEIGHT=640), 안전영역 TOP=24 / BOTTOM=16. 모든 텍스트는 `fontFamily: 'monospace'`.

## 1. 화면 흐름도

```
TitleScene ──(화면 아무데나 탭, 300ms 페이드)──▶ StageSelectScene
StageSelectScene:
  월드 탭(3) → scene.restart / 스테이지 버튼(5) → 위협브리핑 팝업 → [⚔️출격] → GameScene
  하단: 💎영구강화 6행(구매 시 scene.restart로 전체 리빌드)
GameScene 진입 시퀀스: 일시정지 상태 → TutorialPopup(전체 덮개) → 스테이지명 인트로(페이드 텍스트) → W1이면 힌트 토스트 → 플레이 시작
GameScene 내 팝업: Pause / RecipePopup(유닛 탭) / RecipeBook(📖) / SoulShop(🔮) / Reward(보스·미니보스 처치) / GameOver / Victory
GameOver → 다시하기(restart) | 💎이어하기 | 📺광고부활(1.5초 시뮬) | 스테이지선택
Victory → 다시하기 | 무한모드(같은 씬 계속) | 스테이지선택
블러/visibilitychange → 자동 Pause
```

TitleScene은 배경 사각형 + drawPanelAt 장식 패널(260×110) + 44px 금색 타이틀 + 덩굴 점 장식 + 16px 깜빡이는(alpha 0.15↔1) "[ 화면을 터치하여 시작 ]"이 전부. 별도 버튼/설정/로고 없음.

## 3. 터치 인터랙션 전수

| 입력 | 동작 |
|---|---|
| 유닛 드래그 | 이동. dragstart 시 사거리 원 표시 + 유효 파트너에 시안(0x00ffcc) 원(r=22) 펄스 하이라이트 |
| 드래그→다른 유닛 35px 이내 드롭 | T1+T1 동일 카테고리=교배(3초, ❤표시) / 이종 카테고리·T2+T2·T3+T3=합성. 실패 시 스냅백+토스트 |
| 드래그→우하단 판매존 | 판매 (+골드 토스트) |
| 드래그→트랙 위 | 8방향×4스텝(30px 간격) 빈자리 탐색 후 배치, 실패 시 스냅백 |
| 탭(이동거리<8px) | 해당 유닛 RecipePopup + 일시정지 |
| 더블탭(300ms 내 같은 유닛) | 🔒 잠금 토글 (features.lock 해금 시) |
| HUD/팝업 버튼 | 전부 `pointerdown` 즉발. pointerover/out 호버 색 변경(모바일에선 무의미) |
| 딤 배경 탭 | Recipe/RecipeBook/SoulShop/브리핑 닫힘. Reward/Pause/GameOver/Victory는 안 닫힘 |
| 타이틀·튜토리얼 | 화면 전체 탭 |

**터치 타겟 크기**: 유닛 스프라이트 40/46/52/62px(티어별), 이모지 폴백 20~36px. HUD 아이콘 버튼(⏸📖 등) 약 27×19px, 속도 버튼 약 25×19px — 권장 44px에 크게 못 미침. 소환/한도 버튼은 폭은 충분하나 높이 ~26px. 스와이프/핀치/롱프레스 제스처 없음.

## 4. 텍스트 UI vs 그래픽 UI

**모든 버튼이 `Phaser Text + backgroundColor`** — 단색 사각형 배경에 monospace 글자, 라운드 코너·아이콘·그림자·눌림 애니메이션 없음. 개수: StageSelect(월드탭 3, 스테이지 5, 브리핑 2, 강화구매 ~6=16) + HUD(⏸ 📖 2× 소환 한도 영혼상점=6) + Pause(3) + GameOver(4) + Victory(3) + Reward(카드 2~3+확장 1) + Recipe/Book 닫기(2) + SoulShop(강화 2+유닛 6+닫기=9) ≈ **총 45개 전후, 예외 없이 텍스트 버튼**.

그래픽 요소는: (a) artnouveau.ts의 벡터 Graphics — HUD 바, 팝업 패널(3px 금테+1px 내부선+L브래킷 코너+덩굴), 디바이더(금선+점 3개); (b) 유닛 NovelAI 스프라이트 18종(T1 6+T2 12, constants.CHARACTER_ASSETS) — 나머지 유닛 7종(T3/T4 포함)과 **적 전원은 이모지 Text**; (c) 공격 이펙트는 Graphics 선/원/별. HP바는 Graphics 사각형(적 위 20~44×3~5px). 아이콘 이미지 에셋, 나인패치, 비트맵폰트 전무.

- **Pause**: drawPanelAt 290×460. "⏸ 일시정지" 20px + 통계 5줄 14px(시간/골드/유닛/적/보석) + [▶계속][🚪종료] + [🔊/🔇 토글] + DPS 미터(🥇🥈🥉 3줄)
- **RecipePopup**(유닛 탭): 270×가변 패널. 이모지 수식 레시피 줄들(T1: 조합 3개 / T2: 상위 1개 / T3·4: 스탯 4줄+재료). 우상단 " X " 13px

- **Reward**: 326×230 패널 + 딤 0.72. 제목 14px + 카드 2장(±82) 또는 3장(±115,0) — 카드도 12px Text+파랑 배경(pad 10×16) + [💎 선택지 추가]
- **SoulShop**: 310×380. 제목/보유영혼 + 강화 2행(라벨+우측 구매버튼 11px) + 유닛 직접구매 3×2 그리드(이모지+영문명 10px 버튼) + [✖닫기]. 상태 따라 색만 dim 처리
